インストール手順

Android

APK をダウンロードし、端末で開いて画面の指示に従ってください。

Windows

インストーラーをダウンロードし、セットアップウィザードを実行して指示に従ってください。

Apple iOS

App Store からダウンロードしてインストールをタップ。ホーム画面に表示されます。

macOS（Apple）

DMG ファイルをダウンロードし、PrTask をアプリケーションフォルダにドラッグして Launchpad から起動。

Linux システム

配布版に合わせたパッケージをダウンロードし、パッケージマネージャーでインストール。

検証とセキュリティ

すべてのPrTaskダウンロードはデジタル署名され、検証されています。ダウンロード後にSHA-256チェックサムを確認してください。

PrTask をダウンロード — 複数プラットフォーム対応

PrTask は複数プラットフォームでネイティブアプリとして提供され、好みのデバイスからタスク管理、プルリクエストのレビュー、支払いの追跡が可能です。Android アプリはオフライン対応、プッシュ通知、顔認証などを備えたフル機能のモバイル体験を提供します。Windows デスクトップアプリはシステムトレイ連携とローカルファイルアクセスを備えます。Linux 利用者は x64 向けのスタンドアロンバイナリをダウンロードでき、Web アプリは常に prtask.com で最新ブラウザからアクセス可能です。

各プラットフォーム版は .NET MAUI と Blazor による共通コアを採用し、一貫した体験を実現します。ネイティブアプリはキャッシュされたタスクのオフライン参照、プルリクエストや支払いのプッシュ通知、セキュリティ向上のための生体認証ログインといった追加機能を提供します。Web アプリはインストール不要で、どのモダンブラウザでも動作し、最速で利用開始できます。iOS および macOS 版は開発中で、今後リリース予定です。

対応プラットフォームすべてでインストールは簡単です。Android では APK をダウンロードし、不明な提供元からのインストールを許可して画面の指示に従ってください。Windows では実行ファイルを実行するだけでインストーラは不要。Linux ではバイナリをダウンロードして実行権限を与え、ターミナルから起動します。すべてのダウンロードは署名と検証済みで、正当性が保証されています。各プラットフォームの機能を比較表で確認し、インストール時に問題が生じたらトラブルシューティングをご参照ください。
