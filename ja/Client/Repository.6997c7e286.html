リポジトリ管理 - GitHubリポジトリを接続して設定します

リポジトリページでは、クライアントが GitHub リポジトリを PrTask に接続し、スムーズなタスク公開と安全なコード管理を行えます。公開リポジトリまたは非公開リポジトリを追加し、各タスクのソースコードを誰が閲覧できるかを管理できます。

PrTaskで整理された開発ワークフローを維持するには、接続済みリポジトリの管理が不可欠です。タスクを作成する際に、接続済みリポジトリのいずれかにリンクすることで、開発者がコード貢献をどこに提出すべきかを正確に把握できます。公開リポジトリはマーケットプレイス参加者全員に表示され、オープンソースプロジェクトやコミュニティ主導の開発に最適です。非公開リポジトリは招待された開発者のみにアクセスを制限し、コードの閲覧と貢献を制御したい独自コードベースに適しています。

PrTaskは標準API接続を通じてGitHubと統合され、リンクの確立にはリポジトリURLのみが必要です。リポジトリに対する完全なコントロールは維持されます - PrTaskはリポジトリ設定、ブランチ保護、またはアクセス権限を変更しません。すべてのプルリクエストのレビューとマージは既存のGitHubワークフローで行われ、PrTaskはバウンティ支払いとタスク状況の追跡を自動的に処理します。リポジトリを追加していくと、リポジトリページがPrTaskマーケットプレイスに接続されたすべてのコードベースの中央ディレクトリとして機能します。
