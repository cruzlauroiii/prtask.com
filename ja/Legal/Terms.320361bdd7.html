クライアントが pull request を承認すると、登録済みの支払い方法を通じて報奨金額が自動的に請求されます。その後、報奨金の全額が開発者に支払われます。すべての取引は米ドル (PHP) で行われます。プラットフォーム手数料はありません。

9. 公開 pull request

PrTask に提出されるすべての pull request は公開されます。同じ task に対して複数の開発者が pull request を提出できます。Client はすべての提出内容を確認し、どの pull request を承認するかを選択します。支払いの対象となるのは、承認された pull request のみです。

クライアントが pull request を承認すると、bounty amount が自動的に請求されます。Pull request を承認することで、クライアントはその請求を承認したものとみなされます。Upfront deposit は不要です。
