返金ポリシー

最終更新: 2026年3月

この返金ポリシーは、PrTask プラットフォームにおいて返金がいつ、どのように行われるかを説明するものです。PrTask は、クライアントが pull request を承認した時点でのみ課金される自動決済モデルを採用しています。このポリシーは、欧州連合 (European Union, EU)、フィリピン、およびその他の法域の消費者保護法に基づく権利を含む、すべての返金シナリオを対象とします。

1. 自動決済モデル

PrTask は自動決済モデルを採用しています。クライアントは pull request を承認したときにのみ課金されます。タスクを投稿する際に前払いまたはデポジットは不要です。

2. 承認前の請求なし

クライアントは、pull request を明示的に承認するまで課金されません。承認された PR がない場合、支払いは発生しません。クライアントは PR を承認する前であれば、いつでも無料でタスクを取り消すことができます。

3. 承認後の返金

クライアントが pull request を承認して課金されると、bounty は開発者に支払われます。返金は、プラットフォームの誤り、不正行為、または提出された作業が pull request (PR) に記載された内容と実質的に異なる場合にのみ行われます。

4. 係争中のプルリクエスト

クライアントが承認済みのPRがタスク要件を満たしていないと考える場合、PrTaskは仲裁プロセスを開始します。両当事者は7営業日以内に証拠を提出する必要があります。結果として、作業が要件を満たしていない場合はクライアントへの全額返金、作業が要件を満たしている場合は開発者への全額支払い、作業が部分的に満たしている場合は一部返金（配分はPrTaskが決定）となる可能性があります。

5. 放棄されたタスク

タスクに pull request の提出が一件もない場合、クライアントはいつでもそのタスクを終了できます。pull request (PR) が承認されるまで支払いは行われないため、放棄されたタスクについて返金するものはありません。

6. プラットフォームエラー

プラットフォームの誤りにより支払いが不正に処理された場合、PrTask は 3 営業日以内に全額返金を行います。取引参照番号を添えて support@prtask.com までご連絡ください。

7. EUの14日間撤回権

欧州連合または欧州経済領域の居住者である場合、Consumer Rights Directive (2011/83/EU) に基づき、デジタルサービスについて 14 日間の撤回権があります。この権利は取引日から開始します。14 日以内に support@prtask.com へ連絡することで、理由を示すことなくこの権利を行使できます。PrTask は、撤回通知を受領してから 14 日以内に、元の取引と同じ支払い方法で返金を処理します。購入時に明示的な事前同意を与え、デジタルサービス、すなわち開発者への bounty 支払いが完全に履行された時点で撤回権を失うことを認めた場合、この権利は放棄されることがあります。PrTask がこの権利について通知しなかった場合、この権利は自動的に 1 年へ延長されます。

8. フィリピン消費者保護（RA 7394）

フィリピン居住者は、Republic Act No. 7394、すなわち Consumer Act of the Philippines に基づく消費者保護を受ける権利があります。サービスが購入時に示された説明または品質基準を満たさない場合、全額返金または是正措置を受ける権利があります。返金依頼が PrTask の内部手続きで満足のいく形で解決されない場合は、Department of Trade and Industry (DTI) に苦情を申し立てることができます。PrTask は DTI によるあらゆる調査に全面的に協力します。

9. 返金不可項目

次の場合は返金対象となりません。審査と承認が完了し、コードがマージされ、task の要件を満たしている pull request に対する bounty、取引から 30 日を超えて申し立てられた紛争、ならびにクライアントが提出されたコードをすでに使用、配備、または本番環境に組み込んでいる場合です。欧州連合居住者の法定撤回権については、それらの権利が有効に放棄されていない限り、この条項の影響を受けません。

10. 返金の申請方法

返金を依頼するには、PrTaskアカウントにログインし、対象のタスクに移動して「返金をリクエスト」を選択してください。代替として、タスクIDと返金理由を記載し、prtask.com のサポートにメールしてください。すべての返金リクエストは2営業日以内に審査されます。

11. 返金処理の期間

PrTask は次の期間内に返金を処理します。欧州連合の撤回権に基づく返金は撤回通知の受領後 14 日以内、プラットフォームエラーによる返金は 3 営業日以内、紛争解決による返金は決定後 5 営業日以内、その他の返金対象となる返金は承認後 5 営業日以内です。実際に返金を受け取る時期は、利用している銀行または支払いプロバイダーによって異なり、さらに 5 から 10 営業日かかる場合があります。

12. 返金方法

返金は、元の支払い方法に対して処理されます。処理時間はご利用の銀行またはカード発行会社によって異なりますが、通常は承認後 5 営業日から 7 営業日かかります。

13. チャージバックポリシー

クライアントが当社の紛争解決プロセスを利用せずに銀行やクレジットカード発行会社を通じてチャージバックを開始した場合、PrTask は調査が完了するまで当該クライアントのアカウントを停止する権利を留保します。PrTask を通じて解決を試みずにチャージバックを行ったクライアントは、アカウントが恒久的に停止される場合があります。すべてのクライアントに対し、金融機関へ連絡する前に当社の組み込みの紛争および返金プロセスを利用することを推奨します。チャージバックは関係者全員に手数料と遅延を発生させるためです。PrTask は適切な法的手段を通じて資金の回収を追求する権利を留保します。

14. エスクローなしのモデル

PrTask は資金をエスクローで保管しません。bounty は PR が承認された時点でクライアントに直接請求され、そのまま開発者に支払われます。中間的な保留期間はありません。これにより、開発者は速やかに支払いを受け取り、クライアントは承認済みの作業に対してのみ請求されます。

15. Contact

返金の依頼や本ポリシーに関する質問がある場合は、task ID と取引参照番号を添えて support@prtask.com までご連絡ください。欧州連合の消費者として撤回権を行使する場合は、件名に "EU Withdrawal" を含めてください。フィリピンの消費者苦情については、DTI に直接連絡することもできます。

この返金ポリシーについて

この Refund Policy は、PrTask を通じて行われた支払いがどのような条件で返金対象となるかを定めるものです。PrTask では、pull request が承認された時点で bounty が支払われる自動決済モデルを採用しているため、返金手続きはクライアントと開発者の双方にとって公平になるよう設計されています。このポリシーは、作業品質に関する紛争、放棄された task、プラットフォームのエラー、ならびに欧州連合およびフィリピンの消費者保護法に基づく規制要件を含む場面を対象としています。

PrTask は、pull request が承認されるまで開発者に請求せず、クライアントにも task bounty を明示的に資金提供するまで請求しません。この承認時支払いモデルにより、支払いは両当事者が成果物に同意した場合にのみ行われるため、返金の必要性を最小限に抑えます。返金が必要な場合、PrTask はこのポリシーで定める期間内に、元の支払い方法を通じて返金を処理します。返金依頼を開始する場合や取引に異議を申し立てる場合は、support@prtask.com までご連絡ください。
