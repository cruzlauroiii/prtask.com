支払い方法

主要なクレジットカード、デビットカード、その他のサポートされている決済プロバイダーを受け付けています。すべての支払いは安全に処理されます。

出金詳細

開発者は銀行振込、PayPal、またはその他のサポートされている方法で収入を引き出せます。出金は3〜5営業日で処理されます。

返金ポリシー

紛争中または未納品の作業に対して、公平な返金条件を提供しています。クライアントが対象となる場合を確認するには、返金ポリシー全文をご覧ください。

支払い詳細

支払いはどのように処理されますか？

クライアントが pull request を承認すると、選択した支払い方法を通じて報奨金額が自動的に請求されます。

いつ支払いを受け取れますか？

クライアントがあなたの PR を承認すると、自動的に支払いが処理されます。開発者は報奨金の 100% を受け取ります。

対応している通貨は何ですか？

すべての取引は米ドル (PHP) で行われます。

どの支払い方法が利用できますか？

当社の決済プロセッサーを通じて、Visa、Mastercard、American Express、その他主要なクレジットカードおよびデビットカードをご利用いただけます。

報酬を受け取るまでどのくらいかかりますか？

通常、クライアントがあなたの PR を承認してから 3〜5 営業日以内に支払いが処理されます。

最小のバウンティ金額はありますか？

はい。クライアントがタスクに設定できる最低報奨金は 1 PHP です。上限はありません。

始める準備はできましたか？

今日PrTaskに参加して、収入を得るか報酬を投稿しましょう。完全無料です。

無料で登録

PrTaskの料金 — 透明で開発者に優しい

PrTask は開発者にとって非常に有利な料金モデルを採用しています。開発者は費用を一切支払わず、獲得した報奨金の 100% を受け取ります。サブスクリプション料金や手数料率、開発者の支払いから差し引かれる隠れた費用はありません。クライアントが 500 PHP の報奨金でタスクを投稿した場合、タスクを完了しプルリクエストが承認された開発者は 500 PHP を全額受け取ります。この価格構造は、コードを書く人が自分の仕事の価値を全て受け取るべきだという私たちの信念を反映しています。

クライアントにとっても、PrTask は無料で利用できます。クライアントが支払うのは、選択した開発者の pull request が承認されたときに設定していた報奨金額だけです。投稿手数料、掲載手数料、月額のプラットフォーム料金はありません。これにより、PrTask は世界中の経験豊富な開発者にソフトウェアタスクを依頼するための、効率的で低リスクな方法になります。

PrTask の決済処理は、世界中のユーザーに対応できるよう複数の方法をサポートしています。クライアントは主要なクレジットカードやデビットカードで支払いを行え、開発者は自分の地域で利用可能な対応出金オプションを通じて報酬を受け取れます。当社の決済基盤は信頼できるプロバイダーによって支えられており、暗号化された処理とコンプライアンス基準によって安全性が維持されています。
