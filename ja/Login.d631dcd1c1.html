PrTaskにサインイン

アカウントを接続して、収入を得るかタスクを投稿しましょう。

Googleでサインイン GitHubでサインイン Microsoftでサインイン Oktaでサインイン

開発者向け

タスクを閲覧、作業をクレーム、PRを提出、報酬を獲得。

クライアント向け

報酬付きタスクを投稿し、高品質なコードを受け取りましょう。

なぜPrTask？

PrTaskは開発者を有料のオープンソースおよびプライベートタスクとつなぎます。コードを提出し、収入を得て、ポートフォリオを構築しましょう。

報酬を得る

マージされた pull request ごとに報酬を受け取れます。bounty は事前に資金が確保され、マージ時に支払われます。

プラットフォーム手数料なし

開発者は bounty の 100% を受け取ります。PrTask はクライアントに請求し、貢献者には請求しません。

公開 pull request

すべての作業は GitHub 上の実際の pull request として提出されます。あなたの貢献は可視化され、検証可能です。

仕組み

1

Sign In

PrTask アカウントを作成するには、お好みのシングルサインオンプロバイダーで認証してください。

2

タスクを閲覧

言語、フレームワーク、または報酬額で絞り込んで利用可能なタスクを探せます。

3

プルリクエストを送信

タスクを取得し、コードを書き、対象リポジトリに対して pull request を開いてください。

4

支払いを受け取る

あなたの pull request がレビューされてマージされると、bounty は自動的にあなたのアカウントへ支払われます。

セキュリティと信頼

PrTaskはOAuthベースのSSOのみを使用します。パスワードは保存しません。すべての支払いは作業が検証されるまでエスクローに保管されます。

ヘルプが必要ですか？

PrTask にサインイン - 安全な認証オプション

PrTask は信頼できる ID プロバイダーを通じたシングルサインオン（Single Sign-On, SSO）認証を使用し、アカウントへの安全なアクセスを確保します。

PrTask のほとんどの機能にアクセスするには、金融取引とコードの貢献に本人確認済みの身元が必要なため、認証が必須です。初回のサインイン時に PrTask が自動でアカウントを作成し、選択した認証プロバイダーにリンクします。開発者は GitHub アカウントを接続して pull request の送信プロセスを簡素化でき、クライアントは信頼を高める認証済みの身元の恩恵を受けます。認証データはすべて暗号化された接続で送信され、PrTask が認証プロバイダーのパスワードを保存することはありません。

開発者にとって、サインインすることでタスクの閲覧、pull request の送信、報奨金の獲得、leaderboard の順位の追跡が可能になります。クライアントにとっては、タスクの作成、報奨金の資金提供、pull request のレビュー、支払い管理が有効になります。PrTask は複数の連携アカウントをサポートしているため、コード提出用に GitHub、一般的な認証用に Google アカウントをリンクできます。サインイン後に Settings ページへ移動して、連携アカウントの管理、支払い方法の設定、報奨金の引き出しに必要な KYC 検証の完了を行ってください。
