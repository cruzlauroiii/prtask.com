¿Por qué PrTask?

PrTask conecta a desarrolladores con tareas pagadas de código abierto y privadas. Entrega código, gana dinero y construye tu portafolio.

Ganar dinero

Reciba pago por cada pull request fusionado. Las recompensas se financian por adelantado y se liberan al fusionarse.

Sin comisiones de plataforma

Los desarrolladores conservan el 100 % de la recompensa. PrTask cobra a los clientes, nunca a los colaboradores.

Pull requests publicos

Todo el trabajo se entrega como pull requests reales en GitHub. Sus contribuciones son visibles y verificables.

Cómo funciona

1

Sign In

Autentiquese con su proveedor de inicio de sesion unico preferido para crear su cuenta de PrTask.

2

Explorar tareas

Explore las tareas disponibles filtradas por idioma, framework o monto de recompensa.

3

Enviar pull requests

Reclame una tarea, escriba el codigo y abra un pull request contra el repositorio de destino.

4

Recibir pago

Una vez que su pull request sea revisado y fusionado, la recompensa se libera automaticamente a su cuenta.

Seguridad y confianza

PrTask usa exclusivamente SSO basado en OAuth. Nunca almacenamos contraseñas. Todos los pagos se mantienen en custodia hasta que se verifica el trabajo.

Inicie sesion en PrTask: opciones seguras de autenticacion

PrTask utiliza autenticacion de inicio de sesion unico (Single Sign-On, SSO) a traves de proveedores de identidad confiables para garantizar el acceso seguro a su cuenta.

La autenticacion es necesaria para acceder a la mayoria de las funciones de PrTask porque las transacciones financieras y las contribuciones de codigo requieren identidades verificadas. Cuando inicias sesion por primera vez, PrTask crea tu cuenta automaticamente y la vincula con el proveedor de identidad que elijas. Los desarrolladores pueden conectar sus cuentas de GitHub para agilizar el proceso de envio de pull requests, mientras que los clientes se benefician de identidades verificadas que generan confianza en el mercado. Todos los datos de autenticacion se transmiten por conexiones cifradas y PrTask nunca almacena las contrasenas de tu proveedor de identidad.

Para los desarrolladores, iniciar sesion habilita la posibilidad de explorar tareas, enviar pull requests, ganar recompensas y seguir tu posicion en el leaderboard. Para los clientes, la autenticacion permite la creacion de tareas, la financiacion de recompensas, la revision de pull requests y la gestion de pagos. PrTask admite varias cuentas conectadas, por lo que puedes vincular tu GitHub para envios de codigo y tu cuenta de Google para autenticacion general. Visita la pagina de Configuracion despues de iniciar sesion para administrar tus cuentas conectadas, configurar metodos de pago y completar tu verificacion KYC para retirar recompensas.
