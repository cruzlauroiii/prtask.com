Cómo funciona

Primeros pasos

1

Explorar tareas abiertas

Los clientes publican tareas de desarrollo con recompensas. Navega por complejidad, lenguaje o monto de la recompensa.

2

Enviar un Pull Request

Escribe tu código y envía un pull request público. Varios desarrolladores pueden enviar PRs para la misma tarea.

3

Puntuación de complejidad

Tu PR se puntúa automáticamente según los archivos modificados, líneas agregadas, dificultad del lenguaje y cobertura de pruebas.

4

El cliente revisa y aprueba

El cliente revisa todos los PRs enviados y elige el mejor para aprobar. Al aprobar, se cobra automáticamente al cliente el monto de la recompensa.

5

Recibe tu pago

El desarrollador recibe el pago a través de su método preferido. Desbloquea insignias de logros y sube en la tabla de ganancias con cada PR aprobado.

Para clientes

  1. Inicia sesion con GitHub o Google y configura tu metodo de pago
  2. Crea una tarea con descripcion, enlace al repositorio y monto de la recompensa
  3. Los desarrolladores envian pull requests publicos para tu tarea
  4. Revisa todos los pull requests enviados y aprueba el mejor
  5. Se te cobra automaticamente la recompensa y el desarrollador recibe el pago

Cómo funciona PrTask - Guía completa para ganar y contratar

PrTask simplifica el proceso de conectar a desarrolladores con trabajo de software remunerado mediante un flujo de trabajo basado en pull requests que refleja cómo ya operan los equipos profesionales de desarrollo. El proceso comienza con el inicio de sesión usando su cuenta de GitHub, Google, Microsoft u Okta, lo que tarda solo segundos y no requiere un formulario de registro aparte. Una vez autenticados, los desarrolladores pueden explorar las tareas disponibles al instante, mientras que los clientes pueden empezar a crear tareas y fijar recompensas de inmediato. Todo el ciclo de vida, desde la creación de la tarea hasta el desembolso del pago, sigue un flujo predecible y transparente con pasos claros en cada etapa.

Para los desarrolladores, el flujo de trabajo es sencillo: explorar tareas, encontrar una que encaje con sus habilidades, revisar los requisitos y el repositorio de GitHub vinculado, implementar la solución en su propio fork y enviar un pull request a través de PrTask. El propietario de la tarea revisa su código siguiendo las prácticas estándar de revisión de GitHub, puede solicitar cambios y finalmente aprueba y fusiona su contribución. Al fusionarse, el pago se activa automáticamente, sin facturas, sin solicitudes de pago y sin esperar procesamiento manual. La recompensa se desembolsa directamente al método de pago configurado.

Para los clientes, PrTask simplifica la contratación al eliminar entrevistas, contratos y negociaciones de alcance. Cree una tarea con una descripción clara, establezca el nivel de complejidad y el importe de la recompensa, vincúlela a su repositorio de GitHub y publíquela en el marketplace. Los desarrolladores de todo el mundo pueden descubrirla y trabajar en ella. Usted revisa las entregas como pull requests con visibilidad completa del diff, solicita cambios si es necesario y aprueba cuando esté satisfecho. La plataforma gestiona el procesamiento de pagos, la verificación de desarrolladores y la resolución de disputas, para que usted pueda centrarse en revisar la calidad del código en lugar de administrar relaciones con freelancers.
