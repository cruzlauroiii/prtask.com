Instrucciones de instalación

Android

Descarga el archivo APK, ábrelo en tu dispositivo y sigue las indicaciones de la pantalla.

Windows

Descarga el instalador, ejecuta el asistente y sigue las indicaciones para completar la instalación.

iOS de Apple

Descarga desde la App Store y toca Instalar. La app aparecerá en la pantalla principal.

Descarga para macOS

Descarga el archivo DMG, arrastra PrTask a la carpeta Aplicaciones y ábrelo desde Launchpad.

Sistema Linux

Descarga el paquete para tu distribución e instálalo con el gestor de paquetes.

Verificacion y seguridad

Todas las descargas de PrTask estan firmadas digitalmente y verificadas. Comprueba el checksum SHA-256 despues de descargar.

Descarga PrTask — disponible en múltiples plataformas

PrTask ofrece aplicaciones nativas en varias plataformas, de modo que puedes gestionar tareas, revisar pull requests y seguir pagos desde tu dispositivo preferido. La app de Android brinda experiencia móvil completa con soporte offline, notificaciones push y autenticación biométrica. La aplicación de escritorio de Windows ofrece integración nativa en la bandeja del sistema y acceso a archivos locales. Los usuarios de Linux pueden descargar el binario independiente para sistemas x64 y la aplicación web siempre está accesible en prtask.com desde cualquier navegador moderno.

Cada versión comparte el mismo núcleo construido con .NET MAUI y Blazor, garantizando consistencia en todos los dispositivos. Las apps nativas añaden capacidades como acceso offline a datos almacenados, notificaciones push para revisiones y actualizaciones de pagos, y acceso biométrico para mayor seguridad. La app web no requiere instalación y funciona en cualquier dispositivo con navegador moderno, siendo la forma más rápida de comenzar. Las versiones para iOS y macOS están en desarrollo y llegarán en una próxima versión.

La instalación es sencilla en todas las plataformas admitidas. Los usuarios de Android descargan el APK, habilitan la instalación desde orígenes desconocidos y siguen los pasos en pantalla. Los usuarios de Windows descargan el ejecutable y lo ejecutan (no se necesita instalador). Los usuarios de Linux descargan el binario, asignan permisos de ejecución y lo ejecutan desde la terminal. Todas las descargas están verificadas y firmadas para garantizar su autenticidad. Consulte la tabla de comparación de funciones para conocer las capacidades de cada plataforma y la sección de solución de problemas si surge alguna incidencia.
