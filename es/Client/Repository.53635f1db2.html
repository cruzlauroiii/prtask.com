Gestion de repositorios: conecta y configura tus repositorios de GitHub

La pagina Repositorio permite a los clientes conectar sus repositorios de GitHub con PrTask para una publicacion de tareas fluida y una gestion segura del codigo. Puede agregar repositorios publicos o privados y controlar quien puede ver el codigo fuente de cada tarea.

Gestionar sus repositorios conectados es esencial para mantener un flujo de trabajo de desarrollo organizado en PrTask. Cuando crea una tarea, la vincula a uno de sus repositorios conectados para que los desarrolladores sepan exactamente donde deben enviar sus contribuciones de codigo. Los repositorios publicos son visibles para todos los participantes del mercado, lo que los hace ideales para proyectos de codigo abierto y desarrollo impulsado por la comunidad. Los repositorios privados restringen el acceso solo a desarrolladores invitados, adecuados para bases de codigo propietarias donde desea controlar quien puede ver y contribuir a su codigo.

PrTask se integra con GitHub mediante conexiones API estandar, y solo requiere la URL del repositorio para establecer el enlace. Mantiene control total sobre sus repositorios - PrTask no modifica configuraciones del repositorio, protecciones de rama ni permisos de acceso. Todas las revisiones y fusiones de pull requests se realizan a traves de su flujo de trabajo existente de GitHub, mientras PrTask gestiona automaticamente el pago de la recompensa y el seguimiento del estado de la tarea. A medida que agrega mas repositorios, la pagina de Repositorios sirve como su directorio central para todas las bases de codigo conectadas al mercado de PrTask.
