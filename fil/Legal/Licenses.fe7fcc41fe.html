Licenses

Huling na-update: Marso 2026

1. Lisensya ng plataporma

Ang PrTask ay isang proprietary platform na pinapatakbo ng PrTask. Lahat ng karapatan sa platform, disenyo, tatak, at imprastraktura nito ay pag-aari ng PrTask.

2. Pagproseso ng credit card

Ang mga bayad gamit ang credit card sa PrTask ay pinoproseso ng mga lisensyado at PCI DSS-compliant na payment providers. Hindi iniimbak, pinoproseso, o ipinapadala ng PrTask ang mga numero ng credit card, CVV, o iba pang sensitibong cardholder data sa sarili nitong mga server. Lahat ng credit card transactions ay ganap na hinahawakan ng aming payment processor.

3. Pagsunod sa Provider ng Pagbabayad

Ang aming mga payment provider ay may kasalukuyang PCI DSS Level 1 certification, ang pinakamataas na antas ng pagsunod para sa paghawak ng data ng payment card.

4. Proteksyon sa data

Gumagamit ang PrTask ng HTTPS/TLS encryption para sa lahat ng komunikasyon. Ang authentication ay isinasagawa sa pamamagitan ng OAuth 2.0 at OpenID Connect (OIDC) na may PKCE. Walang iniimbak na plaintext credentials. Tingnan ang aming Privacy Policy para sa kumpletong detalye ng paghawak ng data.

5. Pagkilala sa open source

Ang PrTask ay binuo gamit ang .NET, Blazor WebAssembly, at iba pang open source technology. Ginagamit ang mga bahaging ito alinsunod sa kani-kanilang lisensya.

  • .NET Runtime at ASP.NET Core (Lisensyang MIT)
  • Blazor WebAssembly (Lisensya MIT)
  • Mga bahagi ng user interface ng MudBlazor (Lisensyang MIT)

Kami ay nagpapasalamat sa open source na komunidad para sa paggawa ng mga tool na ito na magagamit.

6. Mga atribusyon ng third-party

Isinasama ng PrTask ang mga sumusunod na third-party library at serbisyo. Nagpapasalamat kami sa kanilang mga maintainer at provider sa pagpapagana ng mga kakayahang ito.

  • Para sa kumpletong listahan ng mga dependency at kanilang mga lisensya, tingnan ang project dependency manifest.
  • Mga payment processor (kabilang ang Maya Business): ginagamit para sa ligtas na paghawak ng transaksyon, na napapailalim sa kani-kanilang mga tuntunin at pang-regulasyong kinakailangan.
  • Cloudflare: ginagamit para sa hosting, CDN, at proteksyon laban sa DDoS, na napapailalim sa Mga Tuntunin ng Serbisyo ng Cloudflare.

7. Code na isinumite ng developer

Ang mga pull request na isinumite ng mga developer ay nananatiling intellectual property ng kanilang mga may-akda hanggang mabayaran ang bounty. Kapag nabayaran, ang isinumiteng code ay nililisensya sa kliyente ayon sa lisensyang nakasaad sa repository ng task. Hindi inaangkin ng PrTask ang pagmamay-ari ng anumang code na isinumite ng mga developer.

8. Lisensya ng nilalamang mula sa user

Sa pag-post ng nilalaman sa PrTask (kabilang ang mga paglalarawan ng gawain, komento, at review), binibigyan mo ang PrTask ng hindi eksklusibo, pandaigdigan, at walang royalty na lisensya upang ipakita, kopyahin, at ipamahagi ang nasabing nilalaman para lamang sa layunin ng pagpapatakbo at pagpapabuti ng platform. Nananatili sa iyo ang lahat ng karapatan sa pagmamay-ari ng iyong nilalaman. Nagwawakas ang lisensyang ito kapag tinanggal mo ang iyong nilalaman mula sa PrTask, maliban kung ang nilalaman ay naibahagi o inasahan ng ibang mga user.

9. Mga Karapatan sa Pagmamay-ari ng Code

Pinananatili ng mga developer ang buong pagmamay-ari ng copyright sa lahat ng code na isinusumite nila sa PrTask. Kapag naaprubahan at nabayaran ang bounty, nagbibigay ang developer sa kliyente ng isang walang hanggan, pandaigdigan, hindi eksklusibo, at hindi mababawi na lisensya para gamitin, baguhin, kopyahin, at ipamahagi ang isinumiteng code, alinsunod sa open source license ng repositoryo. Hindi inaangkin ng PrTask ang pagmamay-ari ng anumang code na isinumite ng mga developer. Dapat patunayan ng mga developer na may karapatan silang isumite ang lahat ng code at na hindi ito lumalabag sa mga karapatan sa intelektwal na ari-arian ng ikatlong partido. Ang code na ginawa ng AI (artificial intelligence) ay dapat ibunyag sa paglalarawan ng pull request, at dapat patunayan ng developer na may karapatan silang ilisensya ito.

10. Pagsunod sa regulasyon

Sumusunod ang PrTask sa mga naaangkop na batas at regulasyon kaugnay ng online payment, proteksyon ng datos, at pagpapatakbo ng digital platform.

11. Contact

Para sa mga katanungan sa lisensya, mga tanong sa pagsunod, o mga alalahanin sa pagproseso ng credit card, makipag-ugnayan sa compliance sa prtask.com.

Tungkol sa pahinang ito ng mga Lisensya

Ang pahinang ito ng Licenses ay nagbibigay ng komprehensibong impormasyon tungkol sa mga software license, kasunduan sa payment provider, mga sertipikasyon ng regulatory compliance, at mga patakaran sa intellectual property na namamahala sa platform ng PrTask. Saklaw nito ang mismong platform license, pagsunod sa processing ng credit card, mga integrasyon sa payment provider, mga sertipikasyon sa proteksyon ng data, at ang mga open source component na pinagtayuan ng PrTask. Ang pag-unawa sa mga lisensyang ito ay tumutulong sa iyo na malaman ang iyong mga karapatan at obligasyon kapag ginagamit ang platform.

Ang PrTask ay binuo gamit ang mga open source na teknolohiya kabilang ang .NET, Blazor, at iba't ibang community libraries, at nakatuon kami sa paggalang at pagkilala sa mga lisensya ng lahat ng component na ginagamit namin.
