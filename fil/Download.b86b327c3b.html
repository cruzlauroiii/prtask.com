Mga Tagubilin sa Pag-install

Android

I-download ang APK, buksan ito sa iyong device, at sundin ang mga prompt sa screen.

I-download ang installer, patakbuhin ang setup wizard, at sundin ang mga tagubilin para matapos ang pag-install.

I-download ang DMG file, i-drag ang PrTask sa Applications folder, at buksan mula sa Launchpad.

I-download ang PrTask — Available sa maraming platform

May native apps ang PrTask sa iba't ibang platform, kaya maaari mong pamahalaan ang mga gawain, suriin ang pull requests, at subaybayan ang mga bayad mula sa device na gusto mo. Ang Android app ay may buong mobile experience na may offline support, push notifications, at biometric login. Ang Windows desktop app ay may system tray integration at access sa lokal na file. Ang Linux users ay nagda-download ng standalone binary para sa x64, at lagi nakaka-access ang web app sa prtask.com sa anumang modernong browser.

Parehong core functionality ang ginagamit ng bawat platform sa .NET MAUI at Blazor para pantay-pantay ang experience. Nagbibigay ang native apps ng karagdagang kakayahan tulad ng offline access sa cached task data, push notifications para sa review at payment updates, at biometric login para higit na seguridad. Ang web app ay hindi kailangan ng installation at gumagana sa anumang modernong browser — pinakamabilis na paraan para makapagsimula. Ang mga bersyon para sa iOS at macOS ay kasalukuyang ginagawa at ilalabas sa susunod na update.

Madali lang ang installation sa lahat ng suportadong platform. I-download ang APK, paganahin ang installation mula sa unknown sources, at sundin ang prompts. I-download ang executable sa Windows at patakbuhin — hindi na kailangan ng installer. Para sa Linux, i-download ang binary, lagyan ng execution permission, at patakbuhin mula sa terminal. Lahat ng downloads ay verified at signed para siguraduhin ang authenticity. Tingnan ang feature comparison table para malaman kung ano ang available sa bawat platform at puntahan ang troubleshooting section kapag may problema.
