Walang bayad sa platform — 100% ng gantimpala ang matatanggap ng developer.

Lumikha ng Task — Mag-post ng mga gantimpala para sa gawaing development

Sa pahina ng Create Task, naglalagay ang mga kliyente ng bagong gawaing development sa marketplace ng PrTask. Bawat task ay nangangailangan ng malinaw na pamagat, detalyadong paglalarawan, naka-link na GitHub repository URL, at halagang gantimpala na matatanggap ng mga developer kapag matagumpay ang pagkumpleto. Gabay ng form ang pag-set ng mga parameter upang malaman ng mga developer kung ano ang gagawin, gaano ito kahirap, at kung magkano ang kanilang kikitain. Ang mga malinaw na task ay nakakahikayat ng mas kwalipikadong developer at nagdudulot ng mas mabilis at mataas na kalidad na resulta.

Ang mga antas ng pagiging kumplikado (Napaka-trivial, Simple, Katamtaman, Kumplikado, Eksperto) ay tumutulong sa mga developer na tantiyahin ang inaasahang pagsisikap at kasanayan bago tumanggap ng task. Itakda nang tapat ang pagiging kumplikado — ang pagmamaliit ay magreresulta sa hindi kumpletong submissions, at ang paglalagay ng sobra ay maaaring magpalayo ng mga developer. Ang gantimpala ay dapat mag-reflect ng halaga at kahirapan ng trabaho. May minimum na gantimpala ang PrTask upang tiyakin ang makabuluhang kompensasyon, at nakikita ng developer ang buong halaga nang walang nakatagong bawas. Nakakatulong ang mga tags na ikategorya ang task ayon sa teknolohiya at uri para mas madaling makita.

Maaari mo ring piliin ang uri ng work item (Epic, Feature, Story, Task, Bug) ayon sa iyong pamamahala ng proyekto, at pumili ng pampubliko o pribadong visibility. Ang mga pampublikong task ay nakikita ng lahat ng developer, habang ang pribado ay para lamang sa mga inimbitahang developer. Pagkatapos isumite, agad itong makikita sa Tasks page kung saan puwede itong mahanap at simulan ng mga developer. Binabayaran ang gantimpala kapag inaprubahan at na-merge mo ang panalong pull request, kaya nagbabayad ka lamang sa trabahong nakakatugon sa iyong pamantayan at pumasa sa code review.
