Mga source code repository

Pamahalaan ang iyong mga repository at kontrolin ang visibility ng code para sa mga gawain.

Magdagdag ng repository

Iyong mga repository

Wala pang naidadagdag na repository. Magdagdag ng repository upang makapagsimulang mag-post ng mga gawain.

Pamamahala ng repository - Ikonekta at i-configure ang iyong mga repo sa GitHub

Pinapayagan ng pahinang Repository ang mga kliyente na ikonekta ang kanilang mga GitHub repository sa PrTask para sa maayos na pag-post ng mga gawain at ligtas na pamamahala ng code. Maaari kang magdagdag ng pampubliko o pribadong mga repository at kontrolin kung sino ang makakakita sa source code ng bawat gawain.

Ang pamamahala sa iyong mga konektadong repository ay mahalaga para sa pagpapanatili ng isang organisadong daloy ng trabaho sa pag-unlad sa PrTask.

Kapag gumawa ka ng gawain, ili-link mo ito sa isa sa iyong mga nakakonektang repository para malaman ng mga developer kung saan dapat isumite ang kanilang mga kontribusyon sa code.
