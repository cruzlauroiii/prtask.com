Paano Ito Gumagana

Pagsisimula

1

Mag-browse ng Mga Bukas na Gawain

Nag-post ang mga kliyente ng mga gawain sa development na may bounty. Mag-browse ayon sa complexity, wika, o halaga ng reward.

2

Magsumite ng Pull Request

Isulat ang iyong code at magsumite ng pampublikong pull request. Maraming developer ang maaaring magsumite ng PR para sa parehong gawain.

3

Pag-score ng Complexity

Ang iyong PR ay awtomatikong sino-score batay sa mga binagong file, dagdag na linya, kahirapan ng wika, at test coverage.

4

Rere-review at Aa-approve ang Kliyente

Rere-review ng kliyente ang lahat ng naisumiteng PR at pipiliin ang pinakamahusay na aprubahan. Sa pag-apruba, awtomatikong sisingilin ang kliyente ng halaga ng bounty.

5

Kumita

Matatanggap ng developer ang bayad sa pamamagitan ng kanilang preferred na paraan ng payout. Mag-unlock ng achievement badge at umakyat sa earnings leaderboard sa bawat na-approve na PR.

Para sa mga kliyente

  1. Mag-sign in gamit ang GitHub o Google at i-set up ang iyong paraan ng pagbabayad
  2. Gumawa ng gawain na may paglalarawan, link ng repository, at halaga ng bounty
  3. Nagsusumite ang mga developer ng mga pampublikong pull request para sa iyong gawain
  4. Suriin ang lahat ng naisumiteng pull request at aprubahan ang pinakamahusay
  5. Awtomatikong sisingilin ang bounty at mababayaran ang developer

Paano Gumagana ang PrTask - Kumpletong Gabay sa Pagkita at Pag-hire

Pinapasimple ng PrTask ang pagkokonekta ng mga developer sa bayad na software work sa pamamagitan ng malinaw na daloy mula sa pag-post ng task hanggang sa pagbabayad. Sa halip na mahabang hiring cycle, nakatuon ang platform sa malinaw na scope, bukas na task, at mga pull request na nasusuri agad.

Para sa mga developer, diretso ang proseso: mag-browse ng mga task, pumili ng akmang trabaho, gawin ang pagbabago, at magsumite ng pull request. Kapag na-review at na-approve, awtomatikong inilalabas ang bounty at makikita ang status sa payment history.

Para sa mga kliyente, pinapadali ng PrTask ang pag-hire sa pamamagitan ng pag-alis ng interviews, kontrata, at negosasyon. Mag-post ng malinaw na task, makatanggap ng pull request mula sa mga developer, suriin ang code, at magbayad lamang kapag na-approve ang resulta.
