Mag-sign In sa PrTask

Ikonekta ang iyong account upang magsimulang kumita o mag-post ng gawain.

Mag-sign in gamit ang Google Mag-sign in gamit ang GitHub Mag-sign in gamit ang Microsoft Mag-sign in gamit ang Okta

Para sa mga Developer

Mag-browse ng gawain, mag-claim ng trabaho, magsumite ng PR, at kumita.

Para sa mga Kliyente

Mag-post ng gawain na may bounty at makakuha ng de-kalidad na code.

Bakit PrTask?

Ikinokonekta ng PrTask ang mga developer sa mga bayad na open-source at pribadong gawain. Magpadala ng code, kumita ng pera, at buuin ang iyong portfolio.

Kumita ng pera

Mabayaran sa bawat na-merge na pull request. Ang mga bounty ay naka-pondo na at inilalabas kapag na-merge.

Walang bayad sa plataporma

Napupunta sa mga developer ang 100% ng bounty. Ang PrTask ay naniningil sa mga kliyente, hindi sa mga contributor.

Mga pampublikong pull request

Lahat ng trabaho ay ipinapadala bilang tunay na mga pull request sa GitHub. Nakikita at nabeberipika ang iyong mga ambag.

Paano Gumagana

1

Sign In

Magpatotoo gamit ang paborito mong single sign-on provider upang gawin ang iyong PrTask account.

2

Mag-browse ng mga gawain

Tuklasin ang mga available na gawain na sinala ayon sa wika, framework, o halaga ng bounty.

3

Magsumite ng mga pull request

Kunin ang isang gawain, isulat ang code, at magbukas ng pull request laban sa target na repository.

4

Tumanggap ng bayad

Kapag nasuri at na-merge ang iyong pull request, awtomatikong ilalabas ang bounty sa iyong account.

Seguridad at Tiwala

Ang PrTask ay gumagamit lamang ng OAuth-based SSO. Hindi kami kailanman nag-iimbak ng mga password. Lahat ng mga bayad ay hawak sa escrow hanggang sa ma-verify ang trabaho.

Kailangan ng tulong?

Bisitahin ang aming dokumentasyon para sa mga gabay, FAQ, at mga mapagkukunan ng suporta.

Kailangan ng tulong?

Mag-sign in sa PrTask - mga ligtas na opsyon sa pagpapatotoo

Gumagamit ang PrTask ng single sign-on (SSO) authentication sa pamamagitan ng mga pinagkakatiwalaang identity provider upang matiyak ang ligtas na access sa iyong account.

Kinakailangan ang authentication para ma-access ang karamihan ng mga feature sa PrTask dahil ang mga transaksiyong pinansyal at kontribusyon ng code ay nangangailangan ng na-verify na mga identidad. Kapag unang beses kang nag-sign in, awtomatikong gumagawa ang PrTask ng iyong account at ini-link ito sa napili mong identity provider. Maaaring ikonekta ng mga developer ang kanilang GitHub accounts upang mapadali ang proseso ng pagsusumite ng pull request, habang nakikinabang ang mga kliyente sa mga na-verify na identidad na nagpapalakas ng tiwala sa marketplace. Lahat ng authentication data ay ipinapadala sa pamamagitan ng naka-encrypt na koneksyon at hindi kailanman iniimbak ng PrTask ang mga password ng iyong identity provider.

Para sa mga developer, ang pag-sign in ay nagbibigay-daan na makapag-browse ng mga task, magsumite ng pull request, kumita ng bounties, at subaybayan ang iyong leaderboard ranking. Para sa mga kliyente, pinapagana ng authentication ang paggawa ng task, pagpopondo ng bounty, pag-review ng pull request, at pamamahala ng bayad. Sinusuportahan ng PrTask ang maraming connected accounts, kaya maaari mong i-link ang GitHub mo para sa code submissions at ang Google account mo para sa pangkalahatang authentication. Bisitahin ang Settings page pagkatapos mag-sign in upang pamahalaan ang iyong connected accounts, mag-set up ng mga payment method, at kumpletuhin ang iyong KYC verification para sa bounty withdrawals.
