Tungkol sa PrTask

Ang PrTask ay isang platform kung saan ang mga developer ay kumikita sa pamamagitan ng pagsusumite ng pull request sa mga tunay na proyekto.

Ang Aming Misyon

Ang PrTask ay umiiral upang gawing accessible, patas, at rewarding ang software development para sa lahat. Naniniwala kami na ang mga talentadong developer sa buong mundo ay nararapat na magkaroon ng pantay na access sa makabuluhang trabaho at transparent na kompensasyon anuman ang kanilang tirahan.

Ang Ginagawa Namin

Nag-post ang mga kliyente ng mga gawain sa development na may bounty. Kine-claim ng mga developer ang mga gawain, sumusulat ng code, at nagsusumite ng pull request. Kapag na-review, na-approve, at na-merge ang isang PR, binabayaran ang developer batay sa complexity ng kanilang trabaho.

Ang Aming Kuwento

Itinatag ang PrTask sa isang simpleng ideya: paano kung ang bawat ambag sa code ay may malinaw at garantisadong kalakip na bounty? Isinilang mula sa pagkadismaya sa hindi bayad na open-source na paggawa at sa malalabong freelance platform, inilunsad ang PrTask upang lumikha ng pamilihan kung saan ang mga pull request ang unibersal na salapi ng trabaho. Mula sa aming unang bounty hanggang sa libo-libong natapos na gawain, lumago kami bilang pandaigdigang komunidad ng mga developer at kliyente na may iisang paninindigan sa malinaw at merit-based na pakikipagtulungan.

I-unlock ang mga badge para sa iyong unang PR, ikasampung PR, mga milestone sa kita, at nangungunang mga posisyon sa leaderboard.

Ang bawat pinagsamang PR ay nakakakuha ng mga badge ng tagumpay batay sa mga milestone.

Mga Ligtas na Bayad

Ang mga bounty na bayad ng kliyente ay pinoproseso sa pamamagitan ng mga suportadong payment provider. Kapag na-approve ng kliyente ang isang pull request, awtomatiko silang sinisingil at mababayaran ang developer. Hindi kailangan ng advance na deposito. Pipiliin ng mga developer ang kanilang gustong paraan ng payout.

Mga Pangunahing Halaga

Kalinawan

Bawat gawain, bounty, at bayad ay nakikita. Eksaktong alam ng mga developer kung magkano ang kanilang kikitain bago magsimula, at eksaktong alam ng mga kliyente kung ano ang kanilang binabayaran. Walang mga nakatagong bayarin, walang mga sorpresa.

Pagiging Patas

Ang kompensasyon ay direktang nakatali sa trabahong naihatid. Rere-review ang code batay sa merito nito, hindi sa kung sino ang sumulat nito. Bawat developer ay nakikipagkompetensya sa pantay na larangan na may pantay na pagkakataon.

Bukas na Pinagmulan

Itinataguyod namin ang mga prinsipyo ng open-source. Lahat ng pull request sa PrTask ay pampubliko, nagtataguyod ng pagbabahagi ng kaalaman at mga pamantayan ng kalidad na pinapatnubayan ng komunidad sa bawat proyekto.

Epekto sa Komunidad

Pinapagana ng PrTask ang isang masigla at pandaigdigang komunidad ng mga developer at kliyente na nagtutulungan sa buong mundo upang sama-samang gumawa ng mas magandang software.

Pangako sa Open Source

Ang PrTask ay binuo sa at para sa open-source na ekosistema. Nag-aambag kami pabalik sa komunidad, nagsa-sponsor ng mga open-source maintainer, at tinitiyak na ang bawat linya ng code na isinumite sa aming platform ay nananatiling accessible. Ang aming proseso ng review ay pampubliko, ang aming leaderboard ay pampubliko, at ang aming pangako sa pagiging bukas ay hindi nagbabago.

Tungkol sa PrTask - Ang Aming Misyon at Mga Halaga

Ang PrTask ay itinatag sa paniniwala na ang talento sa software development ay nasa lahat ng dako, ngunit ang mga pagkakataon ay hindi. Ang aming misyon ay i-democratize ang access sa bayad na development work sa pamamagitan ng paglikha ng transparent na marketplace kung saan ang kasanayan at kalidad ng code ang tanging mga salik na mahalaga.

Ang aming mga pangunahing halaga ng transparency, fairness, at open source commitment ang gabay sa bawat desisyon na ginagawa namin. Ang transparency ay nangangahulugang lahat ng mga gawain, bounty, at review ay nakikita ng publiko. Ang fairness ay nangangahulugang pinapanatili ng mga developer ang 100 porsyento ng kanilang bounty earnings.

Ang PrTask ay higit pa sa isang marketplace - ito ay isang komunidad ng mga developer at kliyente na nagbabahagi ng isang pangitain kung paano dapat gumana ang software work. Nag-aalok kami ng mga badge at XP para kilalanin ang mga tagumpay, nagpapanatili ng leaderboard, at nag-aalok ng komprehensibong mga opsyon sa pagbabayad.
