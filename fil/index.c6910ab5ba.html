Ano ang PrTask - Ang Marketplace ng Developer para sa Pull Request Bounty

Ang PrTask ay isang marketplace ng developer na nag-uugnay ng mga kliyente na nangangailangan ng software work sa mga skilled developer na kumukumpleto ng mga gawain sa pamamagitan ng pull request. Ang platform ay gumagana sa isang bounty-based na modelo kung saan ang mga kliyente ay nagpo-post ng mga gawain na may monetary reward at ang mga developer ay kumikita ng mga bounty sa pamamagitan ng pag-submit ng mataas na kalidad na code na pumapasa sa review. Ang bawat gawain sa PrTask ay naka-link sa isang tunay na GitHub repository.

Hindi tulad ng mga tradisyonal na freelancing platform, ang PrTask ay nakatutok lamang sa pull request-based na trabaho. Ang mga developer ay maaaring mag-browse ng mga bukas na gawain, mag-submit ng kanilang mga solusyon bilang pull request, at makatanggap ng awtomatikong bayad kapag ang kanilang code ay na-approve at na-merge.

Ang PrTask ay walang platform fee sa mga developer - natatanggap nila ang 100 porsyento ng bawat bounty na kinita. Itinatakda ng mga kliyente ang halaga ng bounty sa paggawa ng gawain at ang bayad ay awtomatikong pinoproseso pagkatapos ma-approve ang pull request.
