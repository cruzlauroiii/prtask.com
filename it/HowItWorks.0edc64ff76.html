Come funziona

Come iniziare

1

Esplora le attività aperte

I clienti pubblicano attività di sviluppo con ricompense. Sfoglia per complessità, linguaggio o importo della ricompensa.

2

Invia una Pull Request

Scrivi il tuo codice e invia una pull request pubblica. Più sviluppatori possono inviare PR per la stessa attività.

3

Punteggio di complessità

La tua PR viene valutata automaticamente in base ai file modificati, alle righe aggiunte, alla difficoltà del linguaggio e alla copertura dei test.

4

Il cliente esamina e approva

Il cliente esamina tutte le PR inviate e sceglie la migliore da approvare. All'approvazione, al cliente viene addebitato automaticamente l'importo della ricompensa.

5

Ricevi il pagamento

Lo sviluppatore riceve il pagamento tramite il metodo preferito. Sblocca badge di successo e scala la classifica dei guadagni con ogni PR approvata.

Per i clienti

  1. Accedi con GitHub o Google e configura il tuo metodo di pagamento
  2. Crea un'attivita con descrizione, link al repository e importo della bounty
  3. Gli sviluppatori inviano pull request pubbliche per la tua attivita
  4. Esamina tutte le pull request inviate e approva la migliore
  5. La bounty ti viene addebitata automaticamente e lo sviluppatore viene pagato

Come funziona PrTask - guida completa per guadagnare e assumere

PrTask semplifica il collegamento tra sviluppatori e lavoro software retribuito eliminando cicli di assunzione inutili e accelerando la consegna. I clienti pubblicano attivita di ingegneria con ricompense, e gli sviluppatori le risolvono tramite vere pull request su GitHub. Nessun contratto a lungo termine, nessun colloquio, nessuna commissione di piattaforma.

Per gli sviluppatori, il flusso e diretto: sfogliare le attivita, scegliere quella adatta alle proprie competenze, modificare il codice nell'editor di diff, inviare una pull request e ricevere il pagamento automaticamente quando il cliente approva. Ogni attivita mostra chiaramente i dettagli e l'importo della ricompensa.

Per i clienti, PrTask rende piu semplice l'assunzione eliminando colloqui, contratti e ritardi. Pubblica un'attivita, ricevi piu proposte sotto forma di pull request e paga solo quando approvi il lavoro. PrTask gestisce i pagamenti e la verifica dell'identita cosi puoi concentrarti sulla consegna.
