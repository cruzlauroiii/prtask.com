La tua Dashboard PrTask - Panoramica della piattaforma e monitoraggio attivita

La Dashboard fornisce una panoramica centralizzata delle attivita della piattaforma su PrTask. A colpo d occhio, puoi vedere il numero totale di attivita attive, il numero di utenti registrati, il pool totale di bounty e il conteggio delle pull request inviate.

Per gli sviluppatori, la Dashboard serve come punto di partenza per valutare il panorama attuale del lavoro disponibile. Per i clienti, la Dashboard fornisce visibilita sullo stato delle attivita create, incluse le pull request in attesa di revisione.

La Dashboard si aggiorna dinamicamente man mano che vengono create nuove attivita, inviate pull request e pagati bounty. La Dashboard continuera a servire come centro di comando per monitorare tutti gli aspetti della tua attivita su PrTask.
