Gestione dei repository - Collega e configura i tuoi repository GitHub

La pagina Repository consente ai clienti di collegare i propri repository GitHub a PrTask per una pubblicazione fluida delle attivita e una gestione sicura del codice. Puoi aggiungere repository pubblici o privati e controllare chi puo vedere il codice sorgente di ogni attivita.

Gestire i tuoi repository collegati e essenziale per mantenere un flusso di lavoro di sviluppo organizzato su PrTask. Quando crei una task, la colleghi a uno dei tuoi repository collegati in modo che gli sviluppatori sappiano esattamente dove inviare i loro contributi di codice. I repository pubblici sono visibili a tutti i partecipanti del marketplace, rendendoli ideali per progetti open source e sviluppo guidato dalla comunita. I repository privati limitano l'accesso solo agli sviluppatori invitati, adatti a codebase proprietarie in cui desideri controllare chi puo vedere e contribuire al tuo codice.

PrTask si integra con GitHub tramite connessioni API standard, richiedendo solo l'URL del repository per stabilire il collegamento. Mantieni il pieno controllo dei tuoi repository - PrTask non modifica le impostazioni del repository, le protezioni dei branch o i permessi di accesso. Tutte le revisioni e i merge delle pull request vengono eseguiti tramite il tuo flusso di lavoro GitHub esistente, con PrTask che gestisce automaticamente il pagamento della bounty e il monitoraggio dello stato della task. Man mano che aggiungi piu repository, la pagina Repository funge da directory centrale per tutte le codebase collegate al marketplace di PrTask.
