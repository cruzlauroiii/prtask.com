Как это работает

Начало работы

1

Просмотрите открытые задачи

Клиенты публикуют задачи на разработку с вознаграждениями. Просматривайте по сложности, языку или сумме вознаграждения.

2

Отправьте Pull Request

Напишите код и отправьте публичный pull request. Несколько разработчиков могут отправить PR на одну задачу.

3

Оценка сложности

Ваш PR автоматически оценивается по изменённым файлам, добавленным строкам, сложности языка и покрытию тестами.

4

Клиент проверяет и одобряет

Клиент просматривает все отправленные PR и выбирает лучший для одобрения. При одобрении с клиента автоматически списывается сумма вознаграждения.

5

Получите оплату

Разработчик получает оплату через предпочтительный способ. Открывайте значки достижений и поднимайтесь в рейтинге заработка с каждым одобренным PR.

Для клиентов

  1. Войдите через GitHub или Google и настройте способ оплаты
  2. Создайте задачу с описанием, ссылкой на репозиторий и суммой вознаграждения
  3. Разработчики отправляют публичные pull request для вашей задачи
  4. Просмотрите все отправленные pull request и одобрите лучший
  5. Вознаграждение списывается автоматически, а разработчик получает оплату

Руководство по рабочему процессу

Следуйте этим шагам, чтобы пройти весь процесс от входа до оплаты.

1

Войти через единый вход (SSO)

Пройдите аутентификацию через Google, GitHub, Microsoft или Okta.

Sign In Required
2

Проверка личности KYC (знай своего клиента)

Завершите проверку личности, чтобы включить платежи и соблюдать требования регуляторов.

Настройки - KYC Требуется вход
3

Создать задачу

Опубликуйте задачу с вознаграждением, чтобы разработчики могли ее выполнить.

Создать задачу Требуется вход
4

Загрузить исходный код

Загрузите папку с исходным кодом в задачу, чтобы разработчики могли увидеть diff.

Детали задачи Требуется вход
5

Просмотреть открытые задачи

Разработчики просматривают доступные задачи и находят работу, соответствующую их навыкам.

Tasks Open
6

Просмотреть детали задачи

Посмотрите описание задачи, сумму вознаграждения и существующие pull request.

Детали задачи Open
7

Изменить код в редакторе diff

Редактируйте исходный код прямо в браузерном редакторе diff.

Редактор diff Требуется вход
8

Отправить pull request

Отправьте изменения кода как pull request для задачи.

Submit PR Требуется вход
9

Просмотреть изменения кода

Клиент просматривает diff, чтобы увидеть все изменения кода, отправленные разработчиком.

PR Detail Требуется вход
10

Добавить комментарии к ревью

Добавляйте встроенные комментарии к конкретным строкам или выделенному коду, которые требуют изменений.

PR Comments Требуется вход
11

Ответить и закрыть комментарии

Разработчик применяет исправления, отвечает на комментарии и закрывает их.

Закрыть комментарии Требуется вход
12

Одобрить pull request и оплатить через Maya

Клиент одобряет pull request и оплачивает вознаграждение через оплату кредитной картой Maya.

Одобрить и оплатить Payments Требуется вход
13

История платежей

Просматривайте все платежные транзакции и их статус.

Payments Требуется вход
14

Настройки вывода средств

Настройте способ выплат и проверьте баланс на вывод средств.

Settings Требуется вход

Как работает PrTask — полный гид по заработку и найму

PrTask упрощает процесс связи разработчиков с оплачиваемой работой по программированию, устраняя ненужные циклы найма и ускоряя поставку. Клиенты публикуют инженерные задачи с вознаграждением, а разработчики выполняют их через реальные pull request в GitHub. Никаких долгосрочных контрактов, никаких интервью, никаких комиссий платформы.

Для разработчиков поток простой: просмотрите задачи, выберите подходящую по навыкам, внесите изменения в редакторе diff, отправьте pull request и получите оплату автоматически после одобрения клиента. В каждой задаче четко указаны детали и сумма вознаграждения, чтобы вы знали, чего ожидать.

Для клиентов PrTask упрощает найм, исключая интервью, контракты и задержки. Опубликуйте задачу, получите несколько pull request, проверьте код и платите только после одобрения результата. PrTask берет на себя платежи и проверку личности, чтобы вы могли сосредоточиться на поставке.
