Управление репозиториями - подключайте и настраивайте свои репозитории GitHub

Страница репозитория позволяет клиентам подключать свои репозитории GitHub к PrTask для удобной публикации задач и безопасного управления кодом. Вы можете добавлять публичные или приватные репозитории и управлять тем, кто может видеть исходный код каждой задачи.

Управление вашими подключенными репозиториями необходимо для поддержания организованного рабочего процесса разработки на PrTask. Когда вы создаете задачу, вы связываете ее с одним из подключенных репозиториев, чтобы разработчики точно знали, куда отправлять свои вкладки в код. Публичные репозитории видимы всем участникам маркетплейса, что делает их идеальными для проектов с открытым исходным кодом и развития, ориентированного на сообщество. Приватные репозитории ограничивают доступ только приглашенным разработчикам, что подходит для проприетарных кодовых баз, где вы хотите контролировать, кто может просматривать и вносить вклад в ваш код.

PrTask интегрируется с GitHub через стандартные API-подключения, для установления связи требуется только URL репозитория. Вы сохраняете полный контроль над своими репозиториями - PrTask не изменяет настройки репозитория, защиту веток или права доступа. Все проверки и слияния pull request выполняются через ваш существующий рабочий процесс GitHub, а PrTask автоматически обрабатывает выплату вознаграждения и отслеживание статуса задачи. По мере добавления новых репозиториев страница Репозитории служит центральным каталогом для всех кодовых баз, подключенных к маркетплейсу PrTask.
