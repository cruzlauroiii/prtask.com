Инструкция по установке

Android

Скачайте APK-файл, откройте его на устройстве и следуйте подсказкам на экране.

Windows

Скачайте установщик, запустите мастер и следуйте подсказкам для завершения.

Apple iOS

Скачайте из App Store и нажмите Установить. Приложение появится на домашнем экране.

macOS (операционная система Apple)

Скачайте файл DMG, перетащите PrTask в папку Программы и запустите через Launchpad.

Система Linux

Скачайте пакет для вашей дистрибуции и установите через менеджер пакетов.

Верификация и безопасность

Все загрузки PrTask имеют цифровую подпись и верифицированы. Проверьте контрольную сумму SHA-256 после загрузки.

Включите «Установка из неизвестных источников» в настройках и повторите скачивание.

Скачайте PrTask — доступно на нескольких платформах

PrTask доступен как нативное приложение на разных платформах, позволяющее управлять задачами, проверять pull request и отслеживать платежи с любого устройства. Android-версия дает полноценный мобильный опыт с офлайн-доступом, push-уведомлениями и биометрической авторизацией. Для Windows есть настольное приложение с интеграцией в системный трей и доступом к локальным файлам. Пользователи Linux загружают самостоятельный бинарник для x64, а веб-приложение доступно по адресу prtask.com в любом современном браузере.

Все платформенные версии используют общий функциональный базис на .NET MAUI и Blazor, обеспечивая единый интерфейс. Нативные приложения добавляют возможности вроде доступа к кешированным задачам офлайн, push-уведомлений о ревью и платежах и биометрического входа. Веб-приложение не требует установки и работает в любом браузере, что делает его самым быстрым способом начала работы. Версии для iOS и macOS находятся в разработке и появятся в будущих релизах.

Установка проста на всех поддерживаемых платформах. Пользователи Android скачивают APK, разрешают установку из неизвестных источников и следуют подсказкам. Пользователи Windows запускают исполняемый файл напрямую без установщика. Пользователи Linux скачивают бинарник, делают его исполняемым и запускают через терминал. Все загрузки подписаны и проверены для гарантии подлинности. Ознакомьтесь с таблицей сравнения возможностей, чтобы узнать, какие функции доступны на каждой платформе, и перейдите к разделу устранения неполадок при проблемах.
