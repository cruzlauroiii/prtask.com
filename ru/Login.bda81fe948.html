Войти в PrTask

Подключите свой аккаунт, чтобы начать зарабатывать или публиковать задачи.

Войти через Google Войти через GitHub Войти через Microsoft Войти через Okta

Для разработчиков

Просматривайте задачи, берите работу, отправляйте PR и получайте оплату.

Для клиентов

Публикуйте задачи с вознаграждениями и получайте качественный код.

Почему PrTask?

PrTask связывает разработчиков с оплачиваемыми задачами open-source и частными проектами. Пишите код, зарабатывайте и создавайте портфолио.

Зарабатывайте

Получайте оплату за каждый принятый pull request. Вознаграждения финансируются заранее и выпускаются после мерджа.

Без комиссий платформы

Разработчики получают 100% вознаграждения. PrTask взимает плату с клиентов, а не с исполнителей.

Публичные PR

Вся работа выполняется через реальные pull request на GitHub. Ваши вклады видны и проверяемы.

Как это работает

1

Sign In

Войдите через предпочтительный SSO-провайдер, чтобы создать аккаунт PrTask.

2

Просмотр задач

Просматривайте доступные задачи с фильтрами по языку, фреймворку или размеру вознаграждения.

3

Отправлять PR

Возьмите задачу, напишите код и откройте pull request в целевом репозитории.

4

Получайте выплаты

После проверки и мерджа вашего PR вознаграждение автоматически зачисляется на ваш аккаунт.

Безопасность и доверие

PrTask использует исключительно SSO на основе OAuth. Мы никогда не храним пароли. Все платежи хранятся на эскроу до верификации работы.

Нужна помощь?

Посетите нашу документацию с руководствами, FAQ и ресурсами поддержки.

Нужна помощь?

Вход в PrTask — безопасные варианты аутентификации

PrTask использует единый вход (SSO) через надежных провайдеров идентификации, чтобы обеспечить безопасный и быстрый доступ.

Аутентификация требуется для доступа к большинству функций PrTask, поскольку платформа работает с финансовыми транзакциями и персональными данными.

Для разработчиков вход открывает возможность просматривать задачи, отправлять pull request, зарабатывать вознаграждения и получать выплаты.
