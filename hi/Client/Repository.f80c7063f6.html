स्रोत कोड रिपॉजिटरी

अपने रिपॉजिटरी प्रबंधित करें और कार्यों के लिए कोड दृश्यता नियंत्रित करें।

रिपॉजिटरी जोड़ें

आपकी रिपॉजिटरी

अभी तक कोई रिपॉजिटरी नहीं जोड़ी गई है। कार्य पोस्ट करना शुरू करने के लिए एक रिपॉजिटरी जोड़ें।

रिपॉजिटरी प्रबंधन - अपने GitHub रिपोज़ को कनेक्ट और कॉन्फ़िगर करें

रिपॉजिटरी पृष्ठ क्लाइंट को अपने GitHub रिपॉजिटरी को PrTask से जोड़ने देता है ताकि कार्य पोस्ट करना सहज हो और कोड प्रबंधन सुरक्षित रहे। आप सार्वजनिक या निजी रिपॉजिटरी जोड़ सकते हैं और नियंत्रित कर सकते हैं कि प्रत्येक कार्य का स्रोत कोड कौन देख सकता है।

PrTask पर व्यवस्थित विकास कार्यप्रवाह बनाए रखने के लिए आपके जुड़े हुए रिपॉजिटरी का प्रबंधन आवश्यक है। जब आप कोई कार्य बनाते हैं, तो आप उसे अपने जुड़े हुए रिपॉजिटरी में से एक से लिंक करते हैं ताकि डेवलपर जान सकें कि अपने कोड योगदान कहां सबमिट करने हैं। सार्वजनिक रिपॉजिटरी सभी मार्केटप्लेस प्रतिभागियों को दिखाई देती हैं, जिससे वे ओपन सोर्स परियोजनाओं और समुदाय-आधारित विकास के लिए आदर्श होती हैं। निजी रिपॉजिटरी केवल आमंत्रित डेवलपर्स तक पहुंच सीमित करती हैं, जो उन स्वामित्व वाले कोडबेस के लिए उपयुक्त हैं जहां आप नियंत्रित करना चाहते हैं कि कौन आपके कोड को देख और योगदान कर सकता है।

PrTask मानक API कनेक्शनों के माध्यम से GitHub के साथ एकीकृत होता है, और लिंक स्थापित करने के लिए केवल रिपॉजिटरी URL की आवश्यकता होती है। आप अपने रिपॉजिटरी पर पूर्ण नियंत्रण बनाए रखते हैं - PrTask रिपॉजिटरी सेटिंग्स, ब्रांच प्रोटेक्शंस, या एक्सेस अनुमतियों को संशोधित नहीं करता। सभी पुल रिक्वेस्ट समीक्षा और मर्ज आपके मौजूदा GitHub वर्कफ्लो के माध्यम से किए जाते हैं, जबकि PrTask बाउंटी भुगतान और कार्य स्थिति ट्रैकिंग को स्वचालित रूप से संभालता है। जैसे-जैसे आप अधिक रिपॉजिटरी जोड़ते हैं, रिपॉजिटरी पेज PrTask मार्केटप्लेस से जुड़े सभी कोडबेस के लिए आपका केंद्रीय निर्देशिका बनता है।
