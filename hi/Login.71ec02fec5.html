PrTask में साइन इन करें

कमाई शुरू करने या कार्य पोस्ट करने के लिए अपना अकाउंट कनेक्ट करें।

Google से साइन इन करें GitHub से साइन इन करें Microsoft से साइन इन करें Okta से साइन इन करें

डेवलपर्स के लिए

कार्य ब्राउज़ करें, काम क्लेम करें, PR सबमिट करें और भुगतान पाएँ।

क्लाइंट के लिए

बाउंटी के साथ कार्य पोस्ट करें और गुणवत्तापूर्ण कोड प्राप्त करें।

PrTask क्यों?

PrTask डेवलपर्स को भुगतान किए गए ओपन-सोर्स और निजी कार्यों से जोड़ता है। कोड दें, कमाएँ, और अपना पोर्टफोलियो बनाएँ।

पैसा कमाएं

हर मर्ज किए गए pull request पर भुगतान पाएं। bounty पहले से वित्तपोषित होती है और मर्ज होने पर जारी की जाती है।

कोई प्लेटफ़ॉर्म शुल्क नहीं

डेवलपर bounty का 100% रखते हैं। PrTask शुल्क ग्राहकों से लेता है, योगदानकर्ताओं से नहीं।

सार्वजनिक जनसंपर्क

सारा काम GitHub पर वास्तविक pull request के रूप में भेजा जाता है। आपके योगदान दिखाई देते हैं और सत्यापित किए जा सकते हैं।

यह कैसे काम करता है

1

Sign In

अपना PrTask खाता बनाने के लिए अपने पसंदीदा single sign-on प्रदाता से प्रमाणीकरण करें।

2

कार्य ब्राउज़ करें

भाषा, फ्रेमवर्क या बाउंटी राशि के आधार पर फ़िल्टर किए गए उपलब्ध कार्य देखें।

3

पुल रिक्वेस्ट जमा करें

एक कार्य लें, कोड लिखें, और लक्ष्य repository के विरुद्ध एक pull request खोलें।

4

भुगतान प्राप्त करें

आपके pull request की समीक्षा और मर्ज होने के बाद bounty अपने आप आपके खाते में जारी कर दी जाती है।

सुरक्षा और भरोसा

PrTask केवल OAuth-आधारित SSO का उपयोग करता है। हम कभी भी पासवर्ड संग्रहीत नहीं करते। काम सत्यापित होने तक सभी भुगतान एस्क्रो में रखे जाते हैं।

मदद चाहिए?

मार्गदर्शिकाओं, अक्सर पूछे जाने वाले प्रश्नों और सहायता संसाधनों के लिए हमारे दस्तावेज़ देखें।

मदद चाहिए?

PrTask में साइन इन करें - सुरक्षित प्रमाणीकरण विकल्प

PrTask आपके खाते तक सुरक्षित पहुंच सुनिश्चित करने के लिए विश्वसनीय पहचान प्रदाताओं के माध्यम से सिंगल साइन-ऑन (Single Sign-On, SSO) प्रमाणीकरण का उपयोग करता है।

PrTask पर अधिकांश सुविधाओं तक पहुंचने के लिए प्रमाणीकरण की आवश्यकता होती है क्योंकि वित्तीय लेनदेन और कोड योगदान के लिए सत्यापित पहचान की आवश्यकता होती है।

जब आप पहली बार साइन इन करते हैं, तो PrTask स्वचालित रूप से आपका खाता बनाता है और इसे आपके चुने हुए पहचान प्रदाता से लिंक करता है।
