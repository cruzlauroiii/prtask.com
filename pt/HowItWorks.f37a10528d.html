Como funciona

Primeiros passos

1

Explorar tarefas abertas

Clientes publicam tarefas de desenvolvimento com recompensas. Navegue por complexidade, linguagem ou valor da recompensa.

2

Enviar uma Pull Request

Escreva seu código e envie uma pull request pública. Vários desenvolvedores podem enviar PRs para a mesma tarefa.

3

Pontuação de complexidade

Sua PR é pontuada automaticamente com base nos arquivos alterados, linhas adicionadas, dificuldade da linguagem e cobertura de testes.

4

O cliente revisa e aprova

O cliente revisa todas as PRs enviadas e escolhe a melhor para aprovar. Na aprovação, o cliente é cobrado automaticamente pelo valor da recompensa.

5

Receba o pagamento

O desenvolvedor recebe o pagamento pelo método preferido. Desbloqueie conquistas e suba no ranking de ganhos a cada PR aprovada.

Para clientes

  1. Entre com GitHub ou Google e configure sua forma de pagamento
  2. Crie uma tarefa com descricao, link do repositorio e valor da recompensa
  3. Os desenvolvedores enviam pull requests publicos para sua tarefa
  4. Revise todos os pull requests enviados e aprove o melhor
  5. A recompensa e cobrada automaticamente e o desenvolvedor recebe o pagamento

Guia do fluxo de trabalho

Siga estes passos para completar o fluxo completo do login ao pagamento.

1

Entrar via single sign-on (SSO)

Autentique-se com Google, GitHub, Microsoft ou Okta.

Sign In Required
2

Verificacao de identidade KYC (conheca seu cliente)

Conclua a verificacao de identidade para habilitar pagamentos e cumprir regulamentos.

Configuracoes - KYC Login obrigatorio
3

Criar uma tarefa

Publique uma tarefa com recompensa para os desenvolvedores concluirem.

Criar tarefa Login obrigatorio
4

Enviar codigo-fonte

Envie a pasta de codigo-fonte para a tarefa para que os desenvolvedores vejam o diff.

Detalhe da tarefa Login obrigatorio
5

Navegar por tarefas abertas

Desenvolvedores navegam pelas tarefas disponiveis e encontram trabalho que corresponde as suas habilidades.

Tasks Open
6

Ver detalhe da tarefa

Veja a descricao da tarefa, o valor da recompensa e os pull requests existentes.

Detalhe da tarefa Open
7

Modificar codigo no editor de diff

Edite o codigo-fonte diretamente no editor de diff do navegador.

8

Enviar pull request

Envie suas alteracoes de codigo como um pull request para a tarefa.

9

Revisar alteracoes de codigo

O cliente revisa o diff para ver todas as alteracoes de codigo enviadas pelo desenvolvedor.

Adicionar comentarios de revisao

Responder e resolver comentarios

Como o PrTask funciona - guia completo para ganhar e contratar

O PrTask simplifica o processo de conectar desenvolvedores a trabalho de software remunerado, eliminando ciclos de contratacao desnecessarios e acelerando a entrega. Clientes publicam tarefas de engenharia com recompensa, e desenvolvedores as resolvem por meio de pull requests reais no GitHub. Sem contratos de longo prazo, sem entrevistas, sem taxa de plataforma.

Para desenvolvedores, o fluxo e direto: navegar pelas tarefas, escolher uma que combine com suas habilidades, alterar o codigo no editor de diff, enviar um pull request e receber o pagamento automaticamente assim que o cliente aprovar. Cada tarefa mostra claramente os detalhes e o valor da recompensa.

Para clientes, o PrTask facilita a contratacao ao remover entrevistas, contratos e atrasos. Publique uma tarefa, receba varios pull requests, revise o codigo e pague somente quando o trabalho for aprovado. O PrTask cuida dos pagamentos e da verificacao de identidade para que voce foque na entrega.
