Gerenciamento de repositorios - conecte e configure seus repositorios do GitHub

A pagina Repositorio permite que os clientes conectem seus repositorios do GitHub ao PrTask para uma publicacao fluida de tarefas e um gerenciamento seguro do codigo. Voce pode adicionar repositorios publicos ou privados e controlar quem pode ver o codigo-fonte de cada tarefa.

Gerenciar seus repositorios conectados e essencial para manter um fluxo de trabalho de desenvolvimento organizado no PrTask. Quando voce cria uma tarefa, voce a vincula a um de seus repositorios conectados para que os desenvolvedores saibam exatamente onde suas contribuicoes de codigo devem ser enviadas. Repositorios publicos sao visiveis para todos os participantes do marketplace, tornando-os ideais para projetos open source e desenvolvimento orientado pela comunidade. Repositorios privados restringem o acesso apenas a desenvolvedores convidados, adequados para codebases proprietarias nas quais voce deseja controlar quem pode ver e contribuir com seu codigo.

A PrTask integra-se ao GitHub por meio de conexoes de API padrao, exigindo apenas a URL do repositorio para estabelecer o vinculo. Voce mantem controle total sobre seus repositorios - a PrTask nao modifica configuracoes do repositorio, protecoes de branch ou permissoes de acesso. Todas as revisoes e mesclagens de pull requests sao realizadas por meio do seu fluxo de trabalho existente do GitHub, enquanto a PrTask gerencia automaticamente o pagamento da bounty e o acompanhamento do status da tarefa. A medida que voce adiciona mais repositorios, a pagina Repositorios serve como seu diretorio central para todas as codebases conectadas ao marketplace da PrTask.
