Instruções de instalação

Android

Baixe o arquivo APK, abra no dispositivo e siga as instruções da tela.

Windows

Baixe o instalador, execute o assistente e siga os prompts para concluir a instalação.

iOS da Apple

Baixe na App Store e toque em Instalar. O app aparecerá na tela inicial.

Download para macOS

Baixe o arquivo DMG, arraste o PrTask para Aplicativos e abra pelo Launchpad.

Sistema Linux

Baixe o pacote para sua distribuição e instale via gerenciador de pacotes.

Verificacao e seguranca

Todos os downloads do PrTask sao assinados digitalmente e verificados. Verifique o checksum SHA-256 apos o download.

Baixe o PrTask — disponível em várias plataformas

O PrTask está disponível como app nativa em várias plataformas, permitindo gerenciar tarefas, revisar pull requests e acompanhar pagamentos no dispositivo preferido. O app Android oferece experiência completa com suporte offline, notificações push e autenticação biométrica. O app Windows integra-se nativamente à barra de tarefas e permite acesso a arquivos locais. Usuários Linux podem baixar o binário independente para x64 e o app web fica disponível em prtask.com em qualquer navegador moderno.

Todas as versões compartilham o mesmo núcleo criado com .NET MAUI e Blazor, garantindo experiência coerente. Apps nativos disponibilizam recursos adicionais como acesso offline a dados de tarefas, notificações push para revisões e pagamentos, e login biométrico para maior segurança. O app web dispensa instalação e funciona em qualquer dispositivo com navegador moderno, sendo a forma mais rápida de começar. As versões para iOS e macOS estão em desenvolvimento para futuros lançamentos.

A instalação é simples em todas as plataformas suportadas. Usuários Android baixam o APK, ativam a instalação de fontes desconhecidas e seguem as instruções. Usuários Windows baixam o executável e o executam diretamente, sem instalador. Usuários Linux baixam o binário, ativam a permissão de execução e o iniciam pelo terminal. Todos os downloads são assinados e verificados para garantir autenticidade. Consulte a tabela comparativa para conhecer os recursos por plataforma e a seção de solução de problemas em caso de dificuldade.
