Pour les développeurs

Parcourez les tâches, revendiquez du travail, soumettez des PRs et soyez payé.

Pour les clients

Publiez des tâches avec des primes et obtenez du code de qualité.

Pourquoi PrTask ?

PrTask connecte les développeurs à des tâches payées open source et privées. Livrez du code, gagnez de l'argent et développez votre portfolio.

Gagner de l'argent

Soyez paye pour chaque pull request fusionnee. Les primes sont financees a l'avance et versees lors de la fusion.

Aucun frais de plateforme

Les developpeurs conservent 100 % de la prime. PrTask facture les clients, jamais les contributeurs.

Pull requests publics

Tout le travail est livre sous forme de vraies pull requests sur GitHub. Vos contributions sont visibles et verifiables.

Comment ça marche

1

Sign In

Authentifiez-vous avec votre fournisseur d'authentification unique prefere pour creer votre compte PrTask.

2

Parcourir les taches

Explorez les taches disponibles filtrees par langue, framework ou montant de prime.

3

Soumettre des pull requests

Reclamez une tache, ecrivez le code et ouvrez une pull request sur le depot cible.

4

Recevoir le paiement

Une fois votre pull request examinee et fusionnee, la prime est automatiquement versee sur votre compte.

Sécurité et confiance

PrTask utilise exclusivement le SSO basé sur OAuth. Nous ne stockons jamais les mots de passe. Tous les paiements sont conservés sous séquestre jusqu'à vérification du travail.

Besoin d'aide ?

Connectez-vous a PrTask - options d'authentification securisee

PrTask utilise l'authentification par authentification unique (Single Sign-On, SSO) via des fournisseurs d'identite de confiance afin de garantir un acces securise a votre compte.

L'authentification est requise pour acceder a la plupart des fonctionnalites de PrTask, car les transactions financieres et les contributions de code exigent des identites verifiees. Lors de votre premiere connexion, PrTask cree automatiquement votre compte et le relie au fournisseur d'identite que vous avez choisi. Les developpeurs peuvent connecter leurs comptes GitHub pour simplifier le processus de soumission de pull requests, tandis que les clients profitent d'identites verifiees qui renforcent la confiance sur le marche. Toutes les donnees d'authentification sont transmises via des connexions chiffrees et PrTask ne stocke jamais les mots de passe de votre fournisseur d'identite.

Pour les developpeurs, se connecter permet de parcourir les taches, soumettre des pull requests, gagner des bounties et suivre votre classement au leaderboard. Pour les clients, l'authentification permet la creation de taches, le financement des bounties, la revision des pull requests et la gestion des paiements. PrTask prend en charge plusieurs comptes connectes, ce qui vous permet de lier votre GitHub pour les soumissions de code et votre compte Google pour l'authentification generale. Apres connexion, rendez-vous sur la page Settings pour gerer vos comptes connectes, configurer des moyens de paiement et finaliser votre verification KYC pour les retraits de bounties.
