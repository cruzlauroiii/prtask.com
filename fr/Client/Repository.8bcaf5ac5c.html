Gestion des depots - Connecter et configurer vos depots GitHub

La page Depot permet aux clients de connecter leurs depots GitHub a PrTask pour une publication fluide des taches et une gestion securisee du code. Vous pouvez ajouter des depots publics ou prives et controler qui peut voir le code source de chaque tache.

La gestion de vos depots connectes est essentielle pour maintenir un flux de travail de developpement organise sur PrTask. Lorsque vous creez une tache, vous la liez a l'un de vos depots connectes afin que les developpeurs sachent exactement ou soumettre leurs contributions de code. Les depots publics sont visibles pour tous les participants du marche, ce qui les rend ideaux pour les projets open source et le developpement communautaire. Les depots prives restreignent l'acces aux developpeurs invites uniquement, adaptes aux bases de code proprietaires ou vous souhaitez controler qui peut voir et contribuer a votre code.

PrTask s'integre a GitHub via des connexions API standard, ne necessitant que l'URL du depot pour etablir le lien. Vous conservez le controle total de vos depots - PrTask ne modifie pas les parametres du depot, les protections de branche ou les autorisations d'acces. Toutes les revues et fusions de pull requests sont effectuees via votre flux de travail GitHub existant, PrTask gerant automatiquement le paiement de la prime et le suivi du statut des taches. A mesure que vous ajoutez d'autres depots, la page Depots sert de repertoire central pour toutes les bases de code connectees au marche PrTask.
