A propos de l'historique des paiements

La page Historique des paiements offre une vue complete de toutes les transactions financieres associees a votre compte PrTask. Que vous soyez un developpeur recevant des versements de bounties ou un client finançant des bounties de taches, cette page vous donne une transparence totale sur chaque paiement effectue via la plateforme. Chaque enregistrement de transaction comprend la date, la tache associee, le montant, le statut actuel et le type de paiement afin que vous puissiez suivre vos finances en toute confiance.

PrTask traite automatiquement les paiements lorsqu'une pull request est approuvee et fusionnee par le proprietaire de la tache. Les developpeurs recoivent 100 % du montant de la bounty sans frais de plateforme deduits de leurs revenus. Les statuts de paiement se mettent a jour en temps reel, ce qui vous permet de voir si une transaction est en attente, terminee ou requiert votre attention. Vous pouvez filtrer votre historique des paiements en saisissant votre identifiant utilisateur pour afficher les transactions propres a votre compte.

Pour les clients, cette page sert egalement d'enregistrement de tous les versements de bounties effectues aux developpeurs ayant realise vos taches. Vous pouvez recouper les paiements avec des taches precises afin de verifier que les fonds ont ete distribues correctement. Si vous avez des questions sur une transaction particuliere ou si vous devez contester un paiement, PrTask fournit un canal d'assistance dedie accessible depuis les parametres de votre compte. Toutes les donnees de paiement sont chiffrees et stockees de maniere securisee conformement aux normes PCI DSS.
