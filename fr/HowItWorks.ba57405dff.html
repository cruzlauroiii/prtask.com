Comment ça marche

Prise en main

1

Parcourir les tâches ouvertes

Les clients publient des tâches de développement avec des primes. Parcourez par complexité, langage ou montant de la récompense.

2

Soumettre une Pull Request

Écrivez votre code et soumettez une pull request publique. Plusieurs développeurs peuvent soumettre des PRs pour la même tâche.

3

Score de complexité

Votre PR est automatiquement notée en fonction des fichiers modifiés, des lignes ajoutées, de la difficulté du langage et de la couverture des tests.

4

Le client examine et approuve

Le client examine toutes les PRs soumises et choisit la meilleure à approuver. À l'approbation, le client est automatiquement débité du montant de la prime.

5

Soyez payé

Le développeur reçoit le paiement via sa méthode préférée. Débloquez des badges de réussite et grimpez dans le classement des gains à chaque PR approuvée.

Pour les clients

  1. Connectez-vous avec GitHub ou Google et configurez votre mode de paiement
  2. Creez une tache avec une description, un lien de depot et un montant de prime
  3. Les developpeurs soumettent des pull requests publics pour votre tache
  4. Examinez toutes les pull requests soumises et approuvez la meilleure
  5. La prime vous est facturee automatiquement et le developpeur est paye

Comment fonctionne PrTask — Guide complet pour gagner et recruter

PrTask simplifie la mise en relation des developpeurs avec du travail logiciel remunere en supprimant les cycles d'embauche inutiles et en accelerant la livraison. Les clients publient des taches d'ingenierie avec des primes, et les developpeurs les resolvent via de vrais pull requests sur GitHub. Aucun contrat a long terme, aucun entretien, aucun frais de plateforme.

Pour les developpeurs, le flux est simple : parcourir les taches, en choisir une qui correspond a vos competences, modifier le code dans l'editeur de diff, soumettre un pull request, puis etre paye automatiquement des que le client approuve. Chaque tache affiche clairement les details et le montant de la prime afin que vous sachiez a quoi vous attendre.

Pour les clients, PrTask simplifie l'embauche en supprimant les entretiens, les contrats et les retards. Publiez une tache, recevez plusieurs propositions sous forme de pull requests et payez uniquement quand vous approuvez le travail. PrTask se charge des paiements et de la verification d'identite pour que vous puissiez vous concentrer sur la livraison.
