Buat Task — Posting hadiah untuk pekerjaan pengembangan

Halaman Create Task adalah tempat klien memposting pekerjaan pengembangan baru di marketplace PrTask. Setiap task membutuhkan judul yang jelas, deskripsi rinci, URL repositori GitHub terkait, dan jumlah hadiah yang akan diterima pengembang saat berhasil menyelesaikannya. Formulir memandu pengaturan semua parameter agar pengembang tahu apa yang dikerjakan, seberapa kompleks pekerjaan, dan berapa yang akan mereka dapatkan. Task yang terdefinisi dengan baik menarik pengembang berkualitas dan menghasilkan pengiriman yang lebih cepat dan berkualitas tinggi.

Tingkat kompleksitas (Sangat sepele, Sederhana, Menengah, Kompleks, Ahli) membantu pengembang menilai usaha dan keahlian sebelum mengambil task. Tetapkan kompleksitas secara jujur — meremehkan bisa menghasilkan pengiriman tidak lengkap, menaksir terlalu tinggi bisa membuat pengembang ragu. Jumlah hadiah harus mencerminkan kompleksitas dan nilai pekerjaan. PrTask menetapkan hadiah minimum agar kompensasi berarti, dan pengembang melihat jumlah penuh tanpa potongan tersembunyi. Tag mengkategorikan task berdasarkan teknologi dan tipe agar lebih mudah ditemukan.

Anda juga dapat memilih jenis work item (Epic, Feature, Story, Task, Bug) sesuai metodologi manajemen proyek Anda dan memilih antara visibilitas publik atau pribadi. Task publik terlihat oleh semua pengembang, sementara task pribadi hanya untuk pengembang yang diundang. Setelah mengirimkan task, langsung tersedia di halaman Tasks, di mana pengembang dapat menemukannya dan mulai mengerjakannya. Pembayaran hadiah diproses saat Anda menyetujui dan menggabungkan pull request pemenang, memastikan Anda hanya membayar pekerjaan yang memenuhi kebutuhan Anda dan lolos code review.
