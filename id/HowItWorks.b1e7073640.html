Cara Kerja

Mulai

1

Jelajahi Tugas Terbuka

Klien memposting tugas pengembangan dengan hadiah. Jelajahi berdasarkan kompleksitas, bahasa, atau jumlah hadiah.

2

Kirim Pull Request

Tulis kode Anda dan kirimkan pull request publik. Beberapa pengembang dapat mengirim PR untuk tugas yang sama.

3

Penilaian Kompleksitas

PR Anda otomatis dinilai berdasarkan file yang diubah, baris yang ditambahkan, kesulitan bahasa, dan cakupan pengujian.

4

Klien Meninjau dan Menyetujui

Klien meninjau semua PR yang dikirim dan memilih yang terbaik untuk disetujui. Saat disetujui, klien otomatis ditagih sejumlah hadiah.

5

Terima Pembayaran

Pengembang menerima pembayaran melalui metode pilihan mereka. Buka lencana pencapaian dan naiki papan peringkat penghasilan dengan setiap PR yang disetujui.

Untuk klien

  1. Masuk dengan GitHub atau Google dan atur metode pembayaran Anda
  2. Buat tugas dengan deskripsi, tautan repositori, dan jumlah bounty
  3. Pengembang mengirim pull request publik untuk tugas Anda
  4. Tinjau semua pull request yang dikirim dan setujui yang terbaik
  5. Bounty akan dibebankan otomatis kepada Anda dan pengembang dibayar

Cara Kerja PrTask - Panduan Lengkap untuk Menghasilkan Uang dan Merekrut

PrTask menyederhanakan proses menghubungkan developer dengan pekerjaan perangkat lunak berbayar dengan menghilangkan siklus rekrutmen yang tidak perlu dan mempercepat pengiriman. Klien memposting tugas rekayasa dengan bounty, dan developer menyelesaikannya melalui pull request nyata di GitHub. Tanpa kontrak jangka panjang, tanpa wawancara, tanpa biaya platform.

Bagi developer, alurnya sederhana: telusuri tugas, pilih yang sesuai dengan keahlian Anda, ubah kode di editor diff, kirim pull request, lalu dibayar otomatis begitu klien menyetujui. Setiap tugas menampilkan detail dan jumlah bounty dengan jelas agar Anda tahu apa yang diharapkan.

Bagi klien, PrTask mempermudah perekrutan dengan menghilangkan wawancara, kontrak, dan penundaan. Posting tugas, terima beberapa pull request, tinjau kode, dan bayar hanya saat pekerjaan disetujui. PrTask menangani pembayaran dan verifikasi identitas agar Anda bisa fokus pada pengiriman.
