Masuk ke PrTask

Hubungkan akun Anda untuk mulai menghasilkan atau memposting tugas.

Masuk dengan Google Masuk dengan GitHub Masuk dengan Microsoft Masuk dengan Okta

Untuk Pengembang

Jelajahi tugas, klaim pekerjaan, kirim PR, dan terima pembayaran.

Untuk Klien

Posting tugas dengan hadiah dan dapatkan kode berkualitas.

Mengapa PrTask?

PrTask menghubungkan pengembang dengan tugas berbayar open-source dan privat. Kirim kode, hasilkan uang, dan bangun portofolio Anda.

Hasilkan uang

Dapatkan bayaran untuk setiap pull request yang digabungkan. Bounty didanai di muka dan dicairkan saat merge.

Tanpa biaya platform

Developer menerima 100% bounty. PrTask menagih klien, bukan kontributor.

Pull request publik

Semua pekerjaan dikirim sebagai pull request nyata di GitHub. Kontribusi Anda terlihat dan dapat diverifikasi.

Cara Kerja

1

Sign In

Autentikasi dengan penyedia single sign-on pilihan Anda untuk membuat akun PrTask.

2

Jelajahi tugas

Jelajahi tugas yang tersedia berdasarkan bahasa, framework, atau jumlah bounty.

3

Kirim pull request

Klaim tugas, tulis kodenya, dan buka pull request ke repository target.

4

Terima pembayaran

Setelah pull request Anda ditinjau dan digabungkan, bounty otomatis dicairkan ke akun Anda.

Keamanan dan Kepercayaan

PrTask hanya menggunakan SSO berbasis OAuth. Kami tidak pernah menyimpan kata sandi. Semua pembayaran disimpan dalam escrow hingga pekerjaan diverifikasi.

Butuh bantuan?

Kunjungi dokumentasi kami untuk panduan, FAQ, dan sumber dukungan.

Butuh bantuan?

Masuk ke PrTask - opsi autentikasi yang aman

PrTask menggunakan autentikasi single sign-on (SSO) melalui penyedia identitas tepercaya untuk memastikan akses yang aman ke akun Anda.

Autentikasi diperlukan untuk mengakses sebagian besar fitur di PrTask karena transaksi finansial dan kontribusi kode memerlukan identitas yang terverifikasi. Saat Anda masuk untuk pertama kali, PrTask otomatis membuat akun Anda dan menautkannya ke penyedia identitas yang Anda pilih. Developer dapat menghubungkan akun GitHub mereka untuk menyederhanakan proses pengiriman pull request, sementara klien mendapatkan manfaat dari identitas terverifikasi yang membangun kepercayaan di marketplace. Semua data autentikasi ditransmisikan melalui koneksi terenkripsi dan PrTask tidak pernah menyimpan kata sandi penyedia identitas Anda.

Bagi developer, masuk membuka kemampuan untuk menelusuri tugas, mengirim pull request, memperoleh bounty, dan melacak peringkat Anda di leaderboard. Bagi klien, autentikasi memungkinkan pembuatan tugas, pendanaan bounty, peninjauan pull request, dan pengelolaan pembayaran. PrTask mendukung beberapa akun yang terhubung, sehingga Anda dapat menautkan GitHub untuk pengiriman kode dan akun Google untuk autentikasi umum. Kunjungi halaman Settings setelah masuk untuk mengelola akun yang terhubung, menyiapkan metode pembayaran, dan menyelesaikan verifikasi KYC Anda untuk penarikan bounty.
