Aplikasi Web

Petunjuk instalasi

Android

Unduh file APK, buka di perangkat Anda, dan ikuti instruksi layar.

Windows

Unduh installer, jalankan wizard, dan ikuti langkah untuk menyelesaikan instalasi.

iOS Apple

Unduh dari App Store dan ketuk Pasang. Aplikasi akan muncul di layar utama.

macOS (Apple)

Unduh file DMG, seret PrTask ke folder Aplikasi, dan jalankan dari Launchpad.

Sistem Linux

Unduh paket untuk distribusi Anda dan pasang menggunakan pengelola paket.

Verifikasi dan Keamanan

Semua unduhan PrTask ditandatangani secara digital dan diverifikasi. Periksa checksum SHA-256 setelah mengunduh.

Unduh PrTask — Tersedia di banyak platform

PrTask hadir sebagai aplikasi asli di berbagai platform, sehingga Anda dapat mengelola tugas, meninjau pull request, dan melacak pembayaran dari perangkat pilihan. Aplikasi Android menghadirkan pengalaman mobile lengkap dengan dukungan offline, notifikasi push, dan otentikasi biometrik. Aplikasi desktop Windows menawarkan integrasi native ke system tray serta akses file lokal. Pengguna Linux dapat mengunduh binary standalone untuk sistem x64, sementara aplikasi web selalu dapat diakses di prtask.com melalui browser modern.

Setiap versi platform berbagi fungsi inti yang sama yang dibangun dengan .NET MAUI dan Blazor, menjamin pengalaman konsisten. Aplikasi native menyediakan fitur tambahan seperti akses offline ke data tugas yang di-cache, notifikasi push untuk review dan pembaruan pembayaran, serta login biometrik untuk keamanan ekstra. Aplikasi web tidak memerlukan instalasi dan bekerja di perangkat apa pun yang memiliki browser modern, menjadi cara tercepat untuk memulai. Versi iOS dan macOS sedang dikembangkan dan akan tersedia di rilis mendatang.

Instalasi mudah pada semua platform yang didukung. Pengguna Android mengunduh APK, mengizinkan instalasi dari sumber tidak dikenal, dan mengikuti panduan. Pengguna Windows mengunduh file executable dan menjalankannya langsung tanpa installer. Pengguna Linux mengunduh binary, memberi izin eksekusi, dan menjalankannya via terminal. Semua unduhan diverifikasi dan ditandatangani untuk memastikan keasliannya. Periksa tabel perbandingan fitur untuk memahami kemampuan masing-masing platform dan kunjungi bagian pemecahan masalah jika menemukan kendala.
