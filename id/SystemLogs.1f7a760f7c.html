System Event Logs

Every action on a PrTask transaction is recorded as an immutable, append-only event in the platform's audit log. The events for a single task form a complete, tamper-evident chronology from posting through paid delivery. The log excerpt below is the production format, populated with the same example transaction (PR cli/cli#1) used on the delivery receipt page and the confirmation emails page.

Schema: each event contains ts (RFC3339 UTC timestamp), level, event, actor (the user whose action produced the event), taskId, and an event-specific payload. Records are persisted to the AuditLogEntity table and retained for a minimum of 5 years per Philippine BSP / BIR / AMLA requirements.
audit.log - taskId=PRT-cli-cli-1
2019-10-04T03:30:00.142Z INFO  event="task.posted" taskId="PRT-cli-cli-1" actor="@vilmibm" title="interactive pr list" repo="cli/cli" currency="PHP" paymentMethod="maya_card"

Event lifecycle and what each event proves

Every paid PrTask transaction emits the following events in this order. Maya Business reviewers and auditors can request the corresponding rows from the audit log table for any task ID.

EventWhat it provesLinked artifact
task.postedThe cardholder created the task and committed to the no-charge-until-merge model.TaskEntity row + Stage 1 email
pr.submittedA developer responded with a deliverable. No charge yet.PullRequestEntity row + Stage 2 email + GitHub PR
pr.approval_requestedThe cardholder, authenticated and acting on their own session, initiated the approve action.AuditLogEntity row with IP and user agent
pr.mergedDelivery acknowledgment. The cardholder explicitly accepted the deliverable. The merge commit SHA is content-addressed.GitHub merge commit + Stage 3 email + receipt page
payment.capturedCard charged via Maya Business after the cardholder accepted delivery.PaymentEntity row with mayaPaymentId
email.sentSendGrid messageId proves the confirmation email was delivered to the cardholder's verified inbox.SendGrid event webhook log
receipt.generatedThe deep-linked receipt URL is published and remains available for future reference.View receipt

Retention and access

System logs are persisted to the AuditLogEntity table in the platform database, replicated daily to a separate snapshot store, and retained for a minimum of five (5) years from the date of the transaction in line with Philippine BSP, BIR, and AMLA recordkeeping requirements. PrTask will produce the corresponding rows on request from the cardholder, Maya Business, or any competent regulator. Contact support@prtask.com with the receipt number to retrieve a full chronology.
