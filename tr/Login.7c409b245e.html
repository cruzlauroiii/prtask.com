Geliştiriciler İçin

Görevlere göz atın, iş üstlenin, PR gönderin ve ödeme alın.

Müşteriler İçin

Ödüllü görevler yayınlayın ve kaliteli kod alın.

Neden PrTask?

PrTask gelistiricileri ucretli acik kaynak ve ozel gorevlerle bulusturur. Kod gonderin, para kazanin ve portfoyunuzu olusturun.

Para kazan

Birlesen her pull request icin odeme alin. Oduller onceden fonlanir ve birlesme aninda serbest birakilir.

Platform ucreti yok

Gelistiriciler odulun %100'unu alir. PrTask, katkida bulunanlardan degil musterilerden ucret alir.

Kamu PR'leri

Tum calismalar GitHub uzerinde gercek pull request olarak teslim edilir. Katkilariniz gorunur ve dogrulanabilir durumdadir.

Nasil Calisir

1

Sign In

PrTask hesabinizi olusturmak icin tercih ettiginiz tek oturum acma saglayicisi ile kimlik dogrulamasi yapin.

2

Gorevlere goz at

Dil, framework veya odul tutarina gore filtrelenmis mevcut gorevleri kesfedin.

3

Pull request gonder

Bir gorevi alin, kodu yazin ve hedef depoya karsi bir pull request acin.

4

Odemeni al

Pull request'iniz incelenip birlestirildiginde odul otomatik olarak hesabiniza aktarilir.

Guvenlik ve Guven

PrTask yalnizca OAuth tabanli SSO kullanir. Asla sifre saklamayiz. Tum odemeler is dogrulanana kadar emanette tutulur.

Yardima mi ihtiyaciniz var?

PrTask'e giris yapin - guvenli kimlik dogrulama secenekleri

PrTask, hesabiniza guvenli erisim saglamak icin guvenilir kimlik saglayicilari uzerinden tek oturum acma (Single Sign-On, SSO) kimlik dogrulamasini kullanir.

PrTask'teki cogu ozellige erisim icin kimlik dogrulama zorunludur; cunku finansal islemler ve kod katkilari dogrulanmis kimlikler gerektirir. Ilk kez oturum actiginizda PrTask hesabinizi otomatik olarak olusturur ve sectiginiz kimlik saglayicisina baglar. Gelistiriciler pull request gonderim surecini kolaylastirmak icin GitHub hesaplarini baglayabilirken, musteri tarafinda dogrulanmis kimlikler pazaryerinde guven olusturur. Tum kimlik dogrulama verileri sifreli baglantilar uzerinden iletilir ve PrTask kimlik saglayicisi parolalarinizi asla saklamaz.

Gelistiriciler icin oturum acmak, gorevlere goz atma, pull request gonderme, bounty kazanma ve leaderboard siralamanizi takip etme imkanini acar. Musteriler icin kimlik dogrulama; gorev olusturma, bounty finansmani, pull request incelemesi ve odeme yonetimini etkinlestirir. PrTask birden fazla bagli hesabi destekler; bu sayede kod gonderimleri icin GitHub'inizi ve genel kimlik dogrulama icin Google hesabinizi baglayabilirsiniz. Oturum actiktan sonra bagli hesaplarinizi yonetmek, odeme yontemlerini ayarlamak ve bounty cekimleri icin KYC dogrulamanizi tamamlamak icin Settings sayfasini ziyaret edin.
