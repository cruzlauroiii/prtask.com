Depo yonetimi - GitHub depolarinizi baglayin ve yapilandirin

Depo sayfasi, istemcilerin GitHub depolarini PrTask'e baglayarak gorevleri sorunsuz sekilde yayimlamasina ve kodu guvenli bicimde yonetmesine olanak tanir. Her gorevin kaynak kodunu kimin gorebilecegini kontrol ederek herkese acik veya ozel depolar ekleyebilirsiniz.

PrTask'ta duzenli bir gelistirme is akisini surdurmek icin bagli depolarinizi yonetmek esastir. Bir gorev olusturdugunuzda, gelistiricilerin kod katkilarini tam olarak nereye gondereceklerini bilmeleri icin onu bagli depolarinizdan birine baglarsiniz. Herkese acik depolar tum pazar yeri katilimcilarina gorunur, bu da onlarin acik kaynak projeleri ve topluluk odakli gelistirme icin ideal olmasini saglar. Ozel depolar yalnizca davet edilen gelistiricilere erisim saglar ve kodunuzu kimlerin gorebilecegini ve katkida bulunabilecegini kontrol etmek istediginiz ozel kod tabanlari icin uygundur.

PrTask, standart API baglantilari araciligiyla GitHub ile entegre olur ve baglantiyi kurmak icin yalnizca depo URL'si gerektirir. Depolariniz uzerinde tam kontrolu korursunuz - PrTask depo ayarlarini, dal korumalarini veya erisim izinlerini degistirmez. Tum pull request incelemeleri ve birlestirmeleri mevcut GitHub is akisiniz uzerinden yapilir, PrTask ise odul odemesini ve gorev durum takibini otomatik olarak yurutur. Daha fazla depo ekledikce, Depo sayfasi PrTask pazar yerine bagli tum kod tabanlari icin merkezi dizininiz olarak hizmet verir.
