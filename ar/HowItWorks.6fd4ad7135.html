كيف يعمل

البدء

1

تصفح المهام المفتوحة

ينشر العملاء مهام تطوير مع مكافآت. تصفح حسب التعقيد أو اللغة أو مبلغ المكافأة.

2

قدم طلب سحب

اكتب الكود الخاص بك وقدم طلب سحب عام. يمكن لعدة مطورين تقديم PRs لنفس المهمة.

3

تقييم التعقيد

يتم تقييم PR الخاص بك تلقائيًا بناءً على الملفات المعدلة والأسطر المضافة وصعوبة اللغة وتغطية الاختبارات.

4

العميل يراجع ويوافق

يراجع العميل جميع طلبات السحب المقدمة ويختار الأفضل للموافقة عليه. عند الموافقة، يتم تحصيل مبلغ المكافأة من العميل تلقائيًا.

5

احصل على الدفع

يتلقى المطور الدفع عبر طريقته المفضلة. افتح شارات الإنجاز وتسلق لوحة متصدري الأرباح مع كل PR معتمد.

للعملاء

  1. سجّل الدخول باستخدام GitHub أو Google وأعِدَّ طريقة الدفع
  2. أنشئ مهمة بوصف ورابط مستودع ومبلغ مكافأة
  3. يُقدِّم المطورون طلبات دمج عامة لمهمتك
  4. راجع جميع طلبات الدمج المُقدَّمة وافق على الأفضل
  5. يُخصَم منك المكافأة تلقائيًا ويحصل المطور على الدفع

دليل سير العمل

اتبع هذه الخطوات لإكمال سير العمل الكامل من تسجيل الدخول إلى الدفع.

1

تسجيل الدخول عبر SSO

المصادقة عبر Google أو GitHub أو Microsoft أو Okta.

2

التحقق من الهوية KYC

أكمل التحقق من الهوية لتفعيل المدفوعات والامتثال للوائح.

3

إنشاء مهمة

انشر مهمة بمكافأة لإنجازها من قِبَل المطورين.

4

رفع الكود المصدري

ارفع مجلد الكود المصدري للمهمة حتى يتمكن المطورون من رؤية الفرق.

5

تصفح المهام المفتوحة

6

عرض تفاصيل المهمة

تعديل الكود في محرر الفرق

تقديم طلب الدمج

إضافة تعليقات المراجعة

كيف تعمل PrTask — الدليل الشامل للكسب والتوظيف

تُيسِّر PrTask عملية ربط المطورين بعمل برمجي مدفوع الأجر عبر سير عمل قائم على طلبات الدمج يعكس آلية عمل فرق التطوير المهنية. تبدأ العملية بالتسجيل باستخدام حسابك في GitHub أو Google أو Microsoft أو Okta، وهو ما يستغرق ثوانٍ ولا يتطلب نموذج تسجيل منفصل. بعد المصادقة يمكن للمطورين فورًا تصفح المهام المتاحة، بينما يمكن للعملاء البدء في إنشاء المهام وتعيين المكافآت في الحال. تتبع دورة الحياة الكاملة من إنشاء المهمة إلى صرف الدفع سير عملًا شفافًا وقابلًا للتنبؤ مع خطوات واضحة في كل مرحلة.

بالنسبة للمطورين، سير العمل واضح: تصفح المهام وجد مهمة تناسب مهاراتك وراجع المتطلبات ومستودع GitHub المُرتبط ونفِّذ الحل في نسختك الخاصة وقدِّم طلب دمج عبر PrTask. يراجع مالك المهمة كودك وفق ممارسات مراجعة GitHub القياسية وقد يطلب تغييرات ثم يوافق في النهاية على مساهمتك ويدمجها. عند الدمج يُفعَّل الدفع تلقائيًا — لا فواتير، لا طلبات دفع، لا انتظار للمعالجة اليدوية. تُصرَف المكافأة مباشرةً إلى طريقة الصرف التي هيأتها.

بالنسبة للعملاء، تُبسِّط PrTask عملية التوظيف بإلغاء المقابلات والعقود والتفاوض على النطاق. أنشئ مهمة بوصف واضح وحدد مستوى التعقيد ومبلغ المكافأة وارتبط بمستودع GitHub وانشرها في السوق. يمكن للمطورين حول العالم اكتشاف مهمتك والعمل عليها. تراجع التقديمات كطلبات دمج مع رؤية كاملة لفرق الكود وتطلب التغييرات إذا لزم وتوافق عند رضاك. تتولى المنصة معالجة الدفع والتحقق من المطورين وحل النزاعات، مما يتيح لك التركيز على مراجعة جودة الكود بدلاً من إدارة علاقات المستقلين.
