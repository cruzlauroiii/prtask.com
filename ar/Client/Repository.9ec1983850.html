إدارة المستودعات — ربط وتكوين مستودعات GitHub الخاصة بك

تتيح صفحة المستودعات للعملاء ربط مستودعات GitHub الخاصة بهم بـ PrTask لتيسير إدارة المهام وسير عمل طلبات السحب. من خلال ربط مستودع، تمكِّن المطورين من تقديم طلبات السحب مباشرةً على قاعدة الكود الخاصة بك عند العمل على المهام التي نشرتها. يمكن أن يكون لكل مستودع مرتبط اسم عرض مخصص لسهولة التعرف عليه داخل PrTask، وتتحكم إعدادات الظهور في ما إذا كان المستودع مدرجًا علنًا أو مقيدًا على مطورين محددين.

إدارة مستوداتك المرتبطة أمر أساسي للحفاظ على سير عمل تطوير منظم في PrTask. عند إنشاء مهمة، تربطها بأحد مستوداتك المرتبطة حتى يعرف المطورون بالضبط أين ينبغي تقديم مساهمات الكود الخاصة بهم. المستودعات العامة مرئية لجميع المشاركين في السوق، مما يجعلها مثالية للمشاريع مفتوحة المصدر والتطوير المجتمعي. تقيِّد المستودعات الخاصة الوصول على المطورين المدعوين فقط، وهو مناسب للقواعد البرمجية الخاصة حيث تريد التحكم في من يمكنه عرض المحتوى والمساهمة فيه.

تتكامل PrTask مع GitHub عبر اتصالات API القياسية، إذ تتطلب فقط URL المستودع لإنشاء الرابط. تحتفظ بالتحكم الكامل في مستوداتك — لا تعدِّل PrTask إعدادات المستودع أو حمايات الفروع أو أذونات الوصول. تُجرى جميع مراجعات طلبات السحب وعمليات الدمج عبر سير عمل GitHub الحالي لديك، مع قيام PrTask تلقائيًا بمعالجة مدفوعات المكافآت وتتبع حالة المهام. مع إضافة المزيد من المستودعات، تعمل صفحة المستودعات كدليل مركزي لجميع قواعد الكود المتصلة بسوق PrTask.
