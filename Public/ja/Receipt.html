Independent Verification

Every field on this receipt can be independently verified by opening the pull request URL on GitHub. The merge commit SHA is content-addressed: any change to the delivered code changes this hash, so the receipt is tamper-evident. Anyone with the pull request URL (including auditors and the cardholder's bank) can confirm the listed timestamps, author, merger, reviewers, and changed lines without any PrTask account.

Records Retained

PrTask retains the underlying task specification, pull request URL, merge commit SHA, approval log, confirmation emails, and Maya transaction reference for a minimum of five (5) years from the issue date of this receipt.

Questions

For receipt corrections, refund requests, or compliance enquiries, contact support@prtask.com and quote the Receipt Number above.

How this template is populated

  1. Source-of-truth template lives at src/PrTask.SharedUI/Pages/ReceiptPage.razor with route /receipts/{TaskId}. The Razor component reads TaskEntity, PullRequestEntity, PaymentEntity, and UserEntity via the injected services and renders the same fields shown above.
  2. Per-transaction data comes from the platform database for every paid transaction: the task spec, the merged pull request URL, merge commit SHA, timestamps, reviewers, file/line counts, the Maya transaction reference, and the cardholder's accepted-and-merged action.
  3. This static page renders the same template format. Pass ?taskId=<id> to load the receipt for an in-platform transaction; pass ?pr=<GitHub PR URL> to render a receipt populated live from GitHub's public API. Both produce the exact same field set.
  4. Independently verifiable. Open the pull request URL on GitHub - same merge SHA, same merger, same timestamps. No PrTask account required.
