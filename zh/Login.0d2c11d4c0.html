登录 拉取请求任务 - 安全身份验证选项

拉取请求任务 通过受信任的身份提供商使用单点登录 身份验证，以确保您的账户安全。您可以使用现有的 GitHub、谷歌、微软蔚蓝 或 Okta 账户登录，无需为 拉取请求任务 单独创建用户名和密码。此方式利用这些提供商的企业级安全性，包括双因素身份验证、可疑登录检测和账户恢复机制，让您的 拉取请求任务 账户受益于您已有的相同保护措施。

访问 拉取请求任务 大多数功能需要身份验证，因为金融交易和代码贡献需要经过验证的身份。首次登录时，拉取请求任务 会自动创建您的账户并将其关联到您选择的身份提供商。开发者可以连接 GitHub 账户以简化拉取请求提交流程，而客户端则受益于经过验证的身份，从而在市场中建立信任。所有身份验证数据均通过加密连接传输，拉取请求任务 从不存储您的身份提供商密码。

对于开发者，登录后可解锁浏览任务、提交拉取请求、赚取赏金以及追踪排行榜排名等功能。对于客户端，身份验证可启用任务创建、赏金注资、拉取请求审核和支付管理。拉取请求任务 支持多个关联账户，您可以将 GitHub 用于代码提交，将 谷歌 账户用于常规身份验证。登录后请访问设置页面，管理您的关联账户、设置支付方式，并完成 了解您的客户 验证以提取赏金。
