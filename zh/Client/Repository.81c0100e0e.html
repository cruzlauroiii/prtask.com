仓库管理 — 连接并配置您的 GitHub 仓库

仓库页面允许客户将其 GitHub 仓库连接到 拉取请求任务，以实现无缝的任务管理和拉取请求工作流。通过关联仓库，您可以让开发者在处理您发布的任务时直接针对您的代码库提交拉取请求。每个已连接的仓库可以设置自定义显示名称，便于在 拉取请求任务 中识别，可见性设置则控制仓库是公开列出还是仅限特定开发者访问。

管理您的已连接仓库对于在 拉取请求任务 上维护有序的开发工作流至关重要。创建任务时，您需要将其关联到某个已连接的仓库，以便开发者知道应将代码贡献提交到哪里。公开仓库对所有市场参与者可见，非常适合开源项目和社区驱动的开发。私有仓库仅限受邀开发者访问，适合您希望控制谁可以查看和贡献代码的专有代码库。

拉取请求任务 通过标准应用程序接口连接与 GitHub 集成，仅需仓库网址即可建立关联。您对仓库保持完全控制权 — 拉取请求任务 不会修改仓库设置、分支保护或访问权限。所有拉取请求的审查和合并均通过您现有的 GitHub 工作流进行，拉取请求任务 自动处理悬赏金支付和任务状态跟踪。随着您添加更多仓库，仓库页面将成为您所有已连接到 拉取请求任务 市场的代码库的中央目录。
