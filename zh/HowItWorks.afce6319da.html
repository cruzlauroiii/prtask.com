运作方式

快速入门

1

浏览开放任务

客户发布带有赏金的开发任务。按复杂度、语言或奖励金额浏览。

2

提交拉取请求

编写代码并提交公开的拉取请求。多个开发者可以为同一任务提交 拉取请求。

3

复杂度评分

您的 拉取请求 将根据更改的文件、添加的行数、语言难度和测试覆盖率自动评分。

4

客户审查和批准

客户审查所有提交的 拉取请求 并选择最佳方案进行批准。批准后，系统自动向客户收取赏金金额。

5

获得报酬

开发者通过首选支付方式收到报酬。每个获批的 拉取请求 都可解锁成就徽章，并在收入排行榜上攀升。

客户端流程

  1. 使用 GitHub 或 谷歌 登录并设置您的付款方式
  2. 创建包含描述、仓库链接和悬赏金额的任务
  3. 开发者针对您的任务提交公开拉取请求
  4. 审查所有提交的拉取请求并批准最佳方案
  5. 系统自动扣取悬赏金额并向开发者付款

工作流程指南

按照以下步骤完成从登录到付款的完整工作流程。

1

通过 单点登录 登录

使用 谷歌、GitHub、微软 或 Okta 进行 单点登录 认证。

登录 必须完成
2

了解您的客户 身份验证

完成 了解您的客户 身份验证以启用付款功能并符合监管要求。

设置 - 了解您的客户 需要登录
3

创建任务

发布带有悬赏的任务供开发者完成。

创建任务 需要登录
4

上传源代码

将源代码文件夹上传至任务，以便开发者查看差异对比。

任务详情 需要登录
5

浏览开放任务

开发者浏览可用任务，寻找与自身技能匹配的工作。

任务列表 开放
6

查看任务详情

查看任务描述、悬赏金额和现有拉取请求。

任务详情 开放
7

在差异编辑器中修改代码

直接在浏览器差异编辑器中编辑源代码。

差异编辑器 需要登录
8

提交拉取请求

将您的代码更改作为拉取请求提交给任务。

提交 拉取请求 需要登录
9

审查代码变更

客户审查差异内容，查看开发者提交的所有代码变更。

拉取请求 详情 需要登录

添加审查评论

批准并付款 付款记录 需要登录

付款历史

付款记录 需要登录

提现设置

设置 需要登录

拉取请求任务 工作原理 - 赚取收益与招募开发者完整指南

拉取请求任务 通过基于拉取请求的工作流程简化了开发者与付费软件工作的对接过程，该流程与专业开发团队的既有工作方式高度吻合。流程从使用 GitHub、谷歌、微软 或 Okta 账户注册开始，仅需数秒且无需填写单独的注册表单。完成认证后，开发者可立即浏览可用任务，客户可即刻开始创建任务并设置悬赏。从任务创建到付款发放的整个生命周期均遵循可预期、透明的工作流程，每个阶段步骤清晰。

对于开发者而言，工作流程简单直接：浏览任务、找到与您技能匹配的任务、查看需求和关联的 GitHub 仓库、在您自己的 分叉 中实现解决方案，然后通过 拉取请求任务 提交拉取请求。任务所有者按照标准的 GitHub 审查流程审查您的代码，可能会要求修改，并最终批准并合并您的贡献。合并后，付款将自动触发——无需开票、无需申请付款、无需等待人工处理。悬赏将直接发放至您配置的收款方式。

对于客户而言，拉取请求任务 省去了面试、合同签署和范围谈判，简化了招募流程。创建一个描述清晰的任务，设置复杂度级别和悬赏金额，关联您的 GitHub 仓库并发布到市场。全球开发者即可发现并开始处理您的任务。您以拉取请求的形式审查提交内容，可完整查看代码差异，如需修改可提出要求，满意后即可批准。平台负责处理支付、开发者验证和争议解决，让您专注于代码质量审查，而无需管理自由职业者关系。
