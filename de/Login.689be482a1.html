Bei PrTask anmelden

Verbinden Sie Ihr Konto, um Geld zu verdienen oder Aufgaben zu veröffentlichen.

Mit Google anmelden Mit GitHub anmelden Mit Microsoft anmelden Mit Okta anmelden

Für Entwickler

Aufgaben durchsuchen, Arbeit beanspruchen, PRs einreichen und bezahlt werden.

Für Kunden

Veröffentlichen Sie Aufgaben mit Prämien und erhalten Sie qualitativ hochwertigen Code.

Warum PrTask?

PrTask verbindet Entwickler mit bezahlten Open-Source- und privaten Aufgaben. Code liefern, Geld verdienen und Ihr Portfolio aufbauen.

Geld verdienen

Erhalten Sie Vergütung für jeden zusammengeführten Pull Request. Bounties werden im Voraus finanziert und bei der Zusammenführung freigegeben.

Keine Plattformgebühren

Entwickler behalten 100 % des Bounty. PrTask berechnet Kunden, niemals Mitwirkenden.

Öffentliche PRs

Alle Arbeiten werden als echte Pull Requests auf GitHub eingereicht. Ihre Beiträge sind sichtbar und verifizierbar.

So funktioniert es

1

Anmelden

Authentifizieren Sie sich mit Ihrem bevorzugten SSO-Anbieter, um Ihr PrTask-Konto zu erstellen.

2

Aufgaben durchsuchen

Erkunden Sie verfügbare Aufgaben gefiltert nach Sprache, Framework oder Bounty-Betrag.

3

PRs einreichen

Beanspruchen Sie eine Aufgabe, schreiben Sie den Code und öffnen Sie einen Pull Request für das Ziel-Repository.

4

Bezahlt werden

Sobald Ihr PR überprüft und zusammengeführt wurde, wird der Bounty automatisch auf Ihr Konto freigegeben.

Sicherheit und Vertrauen

PrTask verwendet ausschließlich OAuth-basiertes SSO. Wir speichern niemals Passwörter. Alle Zahlungen werden treuhänderisch gehalten, bis die Arbeit verifiziert ist.

Bei PrTask anmelden — Sichere Authentifizierungsoptionen

PrTask verwendet Single Sign-On (SSO)-Authentifizierung über vertrauenswürdige Identitätsanbieter, um die Sicherheit Ihres Kontos zu gewährleisten. Sie können sich mit Ihrem bestehenden GitHub-, Google-, Microsoft Azure- oder Okta-Konto anmelden – Sie müssen für PrTask keinen separaten Benutzernamen und kein Passwort erstellen. Dieser Ansatz nutzt die unternehmensgerechte Sicherheit dieser Anbieter, einschließlich ihrer Zwei-Faktor-Authentifizierung, Erkennung verdächtiger Anmeldungen und Kontowiederherstellungsmechanismen, sodass Ihr PrTask-Konto von denselben Schutzmaßnahmen profitiert, die Sie bereits eingerichtet haben.

Eine Authentifizierung ist erforderlich, um auf die meisten Funktionen von PrTask zuzugreifen, da finanzielle Transaktionen und Code-Beiträge verifizierte Identitäten erfordern. Wenn Sie sich zum ersten Mal anmelden, erstellt PrTask Ihr Konto automatisch und verknüpft es mit Ihrem gewählten Identitätsanbieter. Entwickler können ihre GitHub-Konten verbinden, um den Pull-Request-Einreichungsprozess zu optimieren, während Kunden von verifizierten Identitäten profitieren, die Vertrauen auf dem Marktplatz aufbauen. Alle Authentifizierungsdaten werden über verschlüsselte Verbindungen übertragen und PrTask speichert niemals Ihre Identitätsanbieter-Passwörter.

Für Entwickler ermöglicht die Anmeldung das Durchsuchen von Aufgaben, das Einreichen von Pull Requests, das Verdienen von Bounties und das Verfolgen Ihres Leaderboard-Rankings. Für Kunden ermöglicht die Authentifizierung die Aufgabenerstellung, Bounty-Finanzierung, Pull-Request-Überprüfung und Zahlungsverwaltung. PrTask unterstützt mehrere verbundene Konten, sodass Sie Ihren GitHub für Code-Einreichungen und Ihr Google-Konto für die allgemeine Authentifizierung verknüpfen können. Besuchen Sie nach der Anmeldung die Einstellungsseite, um Ihre verbundenen Konten zu verwalten, Zahlungsmethoden einzurichten und Ihre KYC-Verifizierung für Bounty-Auszahlungen abzuschließen.
