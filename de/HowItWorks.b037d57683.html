So funktioniert es

Erste Schritte

1

Offene Aufgaben durchsuchen

Kunden veröffentlichen Entwicklungsaufgaben mit Prämien. Durchsuchen Sie nach Komplexität, Sprache oder Prämienhöhe.

2

Pull Request einreichen

Schreiben Sie Ihren Code und reichen Sie einen öffentlichen Pull Request ein. Mehrere Entwickler können PRs für dieselbe Aufgabe einreichen.

3

Komplexitätsbewertung

Ihr PR wird automatisch bewertet, basierend auf geänderten Dateien, hinzugefügten Zeilen, Sprachschwierigkeit und Testabdeckung.

4

Kundenprüfung und Genehmigung

Der Kunde überprüft alle eingereichten PRs und wählt den besten zur Genehmigung aus. Bei Genehmigung wird dem Kunden automatisch der Prämienbetrag berechnet.

5

Bezahlt werden

Der Entwickler erhält die Zahlung über seine bevorzugte Auszahlungsmethode. Schalten Sie Auszeichnungen frei und steigen Sie mit jedem genehmigten PR in der Verdienstrangliste auf.

Für Kunden

  1. Melden Sie sich mit GitHub oder Google an und richten Sie Ihre Zahlungsmethode ein
  2. Erstellen Sie eine Aufgabe mit einer Beschreibung, einem Repository-Link und einem Bounty-Betrag
  3. Entwickler reichen öffentliche Pull Requests für Ihre Aufgabe ein
  4. Überprüfen Sie alle eingereichten Pull Requests und genehmigen Sie den besten
  5. Der Bounty wird Ihnen automatisch in Rechnung gestellt und der Entwickler erhält seine Vergütung

Wie PrTask funktioniert — Vollständiger Leitfaden zum Verdienen und Einstellen

PrTask optimiert den Prozess der Verbindung von Entwicklern mit bezahlten Software-Arbeiten durch einen Pull-Request-basierten Workflow, der der Arbeitsweise professioneller Entwicklungsteams entspricht. Der Prozess beginnt mit der Anmeldung über Ihr GitHub-, Google-, Microsoft- oder Okta-Konto, was Sekunden dauert und kein separates Registrierungsformular erfordert. Nach der Authentifizierung können Entwickler sofort verfügbare Aufgaben durchsuchen, während Kunden sofort Aufgaben erstellen und Bounties festlegen können. Der gesamte Lebenszyklus von der Aufgabenerstellung bis zur Zahlungsauszahlung folgt einem vorhersehbaren, transparenten Workflow mit klaren Schritten in jeder Phase.

Für Entwickler ist der Workflow unkompliziert: Aufgaben durchsuchen, eine finden, die Ihren Fähigkeiten entspricht, die Anforderungen und das verknüpfte GitHub-Repository überprüfen, die Lösung in Ihrem eigenen Fork implementieren und einen Pull Request über PrTask einreichen. Der Aufgabeninhaber überprüft Ihren Code nach standardmäßigen GitHub-Überprüfungspraktiken, kann Änderungen anfordern und genehmigt und führt Ihren Beitrag schließlich zusammen. Nach dem Zusammenführen wird die Zahlung automatisch ausgelöst – keine Rechnungsstellung, keine Zahlungsanforderungen, kein Warten auf manuelle Verarbeitung. Der Bounty wird direkt auf Ihre konfigurierte Auszahlungsmethode ausgezahlt.

Für Kunden vereinfacht PrTask den Einstellungsprozess, indem Interviews, Verträge und Auftragsverhandlungen entfallen. Erstellen Sie eine Aufgabe mit einer klaren Beschreibung, legen Sie die Komplexitätsstufe und den Bounty-Betrag fest, verknüpfen Sie sie mit Ihrem GitHub-Repository und veröffentlichen Sie sie auf dem Marktplatz. Entwickler weltweit können Ihre Aufgabe dann entdecken und daran arbeiten. Sie überprüfen Einreichungen als Pull Requests mit vollständiger Code-Diff-Sichtbarkeit, können bei Bedarf Änderungen anfordern und genehmigen, wenn Sie zufrieden sind. Die Plattform übernimmt die Zahlungsabwicklung, Entwicklerverifizierung und Streitbeilegung, sodass Sie sich auf die Überprüfung der Codequalität konzentrieren können, anstatt Freelancer-Beziehungen zu verwalten.
