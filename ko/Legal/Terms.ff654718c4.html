서비스 약관

마지막 업데이트: 2026년 3월

PrTask에 오신 것을 환영합니다. 이 Terms of Service는 PrTask platform에 대한 귀하의 접근과 이용을 규율합니다. PrTask는 clients가 bounty가 있는 tasks를 게시하고 developers가 payment를 위해 pull requests를 제출하는 developer marketplace입니다. Account를 생성하거나 PrTask를 사용함으로써 귀하는 이 Terms에 구속되는 데 동의하게 됩니다. 동의하지 않는 경우 platform을 사용하지 마십시오.

1. 사용자 자격

PrTask를 사용하려면 최소 18세 이상이어야 하며 귀하의 관할권에서 구속력 있는 계약을 체결할 법적 능력이 있어야 합니다. Account를 생성함으로써 귀하는 이러한 eligibility requirements를 충족한다는 점을 진술하고 보증합니다. PrTask는 어떤 jurisdiction에서도 18세 미만 사용자를 대상으로 하지 않습니다. 적용되는 법이 더 높은 성년 연령을 정하는 경우 귀하는 그 기준을 충족해야 합니다.

2. 플랫폼 역할

PrTask는 tasks를 게시하는 clients와 pull requests를 제출하는 developers를 연결하는 intermediary 역할을 합니다. PrTask는 developers를 고용하지 않으며 제공된 work의 quality에 대해 책임지지 않습니다.

3. 계정 생성

PrTask를 사용하려면 GitHub, Google, Microsoft 또는 Okta와 같은 지원되는 single sign-on (SSO) provider를 통해 인증하여 계정을 만들어야 합니다. 귀하는 계정 자격 증명의 보안을 유지할 책임이 있으며, 귀하의 계정에서 발생하는 모든 활동에 대해 책임을 집니다. 등록하는 동안 정확하고 완전한 정보를 제공해야 하며 계정 정보를 최신 상태로 유지해야 합니다. 둘 이상의 계정을 만들거나 다른 사람과 계정을 공유할 수 없습니다.

4. 개발자 의무

PrTask의 개발자로서 귀하는 다음에 동의합니다. 라이선스를 부여할 권리가 있는 원본 작업만 제출할 것; pull request 설명에 AI 생성 코드 사용을 공개할 것; 각 작업의 저장소에 대한 오픈 소스 라이선스 요구 사항을 준수할 것; 어떤 지급을 받기 전에 KYC 신원 확인을 완료할 것; 표절, 도난, 무라이선스 코드를 제출하지 않을 것; 플랫폼의 모든 상호작용에서 전문적인 행동을 유지할 것; 그리고 세무 보고 의무를 포함하여 귀하의 관할권에서 적용되는 모든 법률 및 규정을 준수할 것.

5. 클라이언트 의무

PrTask의 클라이언트는 작업 설명과 요구사항을 명확하고 정확하게 제공하고, pull request를 신속히 검토하며, 승인 후에만 보상을 지급하고, 개발자의 지적 재산권을 존중하며, 관련 법률을 준수하는 데 동의합니다.

6. 결제 조건

클라이언트가 pull request를 승인하면 등록된 결제 수단을 통해 bounty 금액이 자동으로 청구됩니다. 이후 bounty 전액이 개발자에게 지급됩니다. 모든 거래는 미국 달러(PHP)로 처리됩니다. 플랫폼 수수료는 없습니다.

7. 허용되는 결제 수단

클라이언트는 신용카드를 포함한 지원되는 결제 수단을 통해 bounty를 지불합니다. 개발자는 자신이 선택한 방법으로 payout을 받습니다. 개발자는 pull request를 제출하기 전에 account settings에서 선호하는 payout method를 설정해야 합니다.

8. 플랫폼 수수료

PrTask는 무료 플랫폼입니다. 클라이언트나 개발자에게 수수료가 부과되지 않습니다. PR 승인 시 개발자는 bounty 금액의 100%를 받습니다.

9. 공개 pull request

PrTask에 제출되는 모든 pull request는 공개됩니다. 같은 task에 대해 여러 개발자가 pull request를 제출할 수 있습니다. Client는 모든 제출물을 검토하고 어떤 pull request를 승인할지 선택합니다. 승인된 pull request만 결제로 이어집니다.

10. 자동 결제

클라이언트가 pull request를 승인하면 bounty amount가 자동으로 청구됩니다. Pull request를 승인함으로써 클라이언트는 해당 청구를 승인하게 됩니다. Upfront deposit은 필요하지 않습니다.

11. 환불 권리

pull request가 실수로 승인되었거나 납품물이 작업 요구사항을 충족하지 못한 경우, 클라이언트는 환불 정책에 따라 환불을 요청할 수 있습니다.

12. 지적 재산

PrTask를 통해 제출된 모든 코드는 bounty 가 지급될 때까지 해당 작성자의 지적 재산으로 남습니다. 지급이 이루어지면 제출된 코드는 repository 의 라이선스에 따라 클라이언트에게 라이선스됩니다. 사용자 제출 코드에 대해 PrTask는 어떠한 소유권도 보유하지 않습니다.

13. 라이선스 부여

보상이 승인되고 지급되면, 개발자는 본 약관에 따라 납품된 작업을 사용할 수 있도록 영구적이고 전 세계적이며 비독점적이고 로열티가 없는 라이선스를 클라이언트에게 부여합니다.
