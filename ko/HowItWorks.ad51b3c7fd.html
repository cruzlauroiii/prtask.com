이용 방법

시작하기

1

열린 작업 둘러보기

클라이언트가 보상이 있는 개발 작업을 게시합니다. 복잡도, 언어 또는 보상 금액별로 둘러보세요.

2

풀 리퀘스트 제출

코드를 작성하고 공개 풀 리퀘스트를 제출하세요. 여러 개발자가 같은 작업에 PR을 제출할 수 있습니다.

3

복잡도 점수

PR은 변경된 파일, 추가된 줄 수, 언어 난이도 및 테스트 커버리지를 기반으로 자동 점수가 매겨집니다.

4

클라이언트 검토 및 승인

클라이언트가 제출된 모든 PR을 검토하고 최적의 것을 승인합니다. 승인 시 클라이언트에게 보상 금액이 자동 청구됩니다.

5

보수 받기

개발자는 선호하는 지급 방법으로 보수를 받습니다. 승인된 PR마다 업적 배지를 해제하고 수익 리더보드에서 순위를 올리세요.

클라이언트를 위한 안내

  1. GitHub 또는 Google로 로그인하고 결제 수단을 설정하세요
  2. 설명, 저장소 링크, 바운티 금액이 포함된 작업을 만드세요
  3. 개발자가 작업에 대해 공개 풀 리퀘스트를 제출합니다
  4. 제출된 모든 풀 리퀘스트를 검토하고 가장 좋은 것을 승인하세요
  5. 바운티가 자동으로 청구되고 개발자에게 지급됩니다

워크플로 가이드

로그인부터 결제까지 전체 워크플로를 완료하려면 다음 단계를 따르세요.

1

단일 로그인(SSO)으로 로그인

Google, GitHub, Microsoft 또는 Okta로 인증합니다.

Sign In Required
2

KYC 신원 확인(고객 신원 확인)

결제를 활성화하고 규정을 준수하기 위해 신원 확인을 완료합니다.

설정 - KYC 로그인 필요
3

작업 생성

개발자가 완료할 수 있도록 바운티가 포함된 작업을 게시합니다.

작업 생성 로그인 필요
4

소스 코드 업로드

개발자가 diff를 볼 수 있도록 작업에 소스 코드 폴더를 업로드합니다.

작업 상세 로그인 필요
5

열려 있는 작업 보기

개발자는 사용 가능한 작업을 둘러보고 자신의 역량에 맞는 일을 찾습니다.

Tasks Open
6

작업 상세 보기

작업 설명, 바운티 금액, 기존 풀 리퀘스트를 확인합니다.

작업 상세 Open
7

diff 편집기에서 코드 수정

브라우저 diff 편집기에서 소스 코드를 직접 편집합니다.

diff 편집기 로그인 필요
8

풀 리퀘스트 제출

작업에 대한 코드 변경 사항을 풀 리퀘스트로 제출합니다.

Submit PR 로그인 필요
9

코드 변경 사항 검토

클라이언트가 diff를 검토하여 개발자가 제출한 모든 코드 변경 사항을 확인합니다.

PR Detail 로그인 필요
10

리뷰 코멘트 추가

변경이 필요한 특정 줄이나 강조 표시된 코드에 인라인 댓글을 추가합니다.

PR Comments 로그인 필요
11

코멘트 답변 및 해결

개발자가 수정 사항을 반영하고 코멘트에 답하며 이를 해결합니다.

코멘트 해결 로그인 필요
12

풀 리퀘스트 승인 및 Maya로 결제

클라이언트가 풀 리퀘스트를 승인하고 Maya 신용카드 결제로 바운티를 지불합니다.

승인 및 결제 Payments 로그인 필요
13

결제 내역

모든 결제 거래와 상태를 확인합니다.

Payments 로그인 필요
14

출금 설정

지급 방법을 설정하고 출금 잔액을 확인합니다.

Settings 로그인 필요

PrTask 작동 방식 - 수익 창출과 채용을 위한 완전 가이드

PrTask는 개발자와 유료 소프트웨어 작업을 연결하는 과정을 단순화하여 불필요한 채용 사이클을 없애고 납품 속도를 높입니다. 클라이언트는 바운티가 포함된 엔지니어링 작업을 게시하고, 개발자는 GitHub의 실제 풀 리퀘스트로 이를 해결합니다. 장기 계약도, 면접도, 플랫폼 수수료도 없습니다.

개발자 입장에서는 흐름이 간단합니다. 작업을 둘러보고, 자신의 역량에 맞는 것을 선택하고, diff 편집기에서 코드를 수정한 뒤 풀 리퀘스트를 제출하면 클라이언트가 승인하는 즉시 자동으로 지급됩니다. 각 작업에는 상세 정보와 바운티 금액이 명확히 표시됩니다.

클라이언트에게는 면접, 계약, 지연을 제거하여 채용을 간소화합니다. 작업을 게시하고 여러 개의 풀 리퀘스트를 받은 뒤 코드를 검토하고, 결과를 승인할 때만 비용을 지불합니다. PrTask가 결제와 신원 확인을 처리하므로 납품에 집중할 수 있습니다.
