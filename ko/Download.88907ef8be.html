PrTask 다운로드 — 여러 플랫폼에서 사용 가능

PrTask는 여러 플랫폼에서 네이티브 앱으로 제공되어 선호하는 디바이스에서 작업을 관리하고, 풀 리퀘스트를 검토하며, 결제를 추적할 수 있습니다. Android 앱은 오프라인 지원, 푸시 알림, 생체 인증을 갖춘 전체 모바일 경험을 제공합니다. Windows 데스크톱 앱은 시스템 트레이 통합과 로컬 파일 접근을 제공하며, Linux 사용자는 x64 시스템용 독립 실행형 바이너리를 다운로드할 수 있습니다. 웹 앱은 언제든지 prtask.com에서 최신 브라우저로 접근 가능합니다.

모든 플랫폼 버전은 .NET MAUI와 Blazor 기반의 동일한 핵심 기능을 공유하여 디바이스 간 일관된 경험을 제공합니다. 네이티브 앱은 캐시된 작업 데이터의 오프라인 액세스, 풀 리퀘스트 검토 및 결제 업데이트를 위한 푸시 알림, 보안을 강화하는 생체 로그인과 같은 추가 기능을 제공합니다. 웹 앱은 설치가 필요 없으며 모든 현대 브라우저에서 작동해 가장 빠르게 시작할 수 있는 방법입니다. iOS와 macOS 버전은 개발 중이며 향후 릴리스됩니다.

지원되는 모든 플랫폼에서 설치는 간편합니다. Android 사용자는 APK를 다운로드하여 기기 설정에서 알 수 없는 출처 허용을 활성화한 후 화면 안내를 따릅니다. Windows 사용자는 실행 파일을 다운로드하여 바로 실행하면 되고 설치 프로그램은 필요 없습니다. Linux 사용자는 바이너리를 다운로드해 실행 권한을 부여한 뒤 터미널에서 실행합니다. 모든 다운로드는 정품 확인을 위해 서명 및 검증됩니다. 각 플랫폼의 기능 비교표를 확인하고 설치 과정에서 문제가 발생하면 문제 해결 섹션을 참고하세요.
