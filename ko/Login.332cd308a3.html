PrTask 로그인

계정을 연결하여 수익을 얻거나 작업을 게시하세요.

Google로 로그인 GitHub으로 로그인 Microsoft로 로그인 Okta로 로그인

개발자용

작업을 둘러보고, 맡고, PR을 제출하고 보수를 받으세요.

클라이언트용

보상이 있는 작업을 게시하고 양질의 코드를 받으세요.

왜 PrTask인가?

PrTask는 개발자를 유료 오픈소스 및 프라이빗 작업과 연결합니다. 코드를 제출하고, 수입을 얻고, 포트폴리오를 구축하세요.

수익 얻기

병합된 pull request마다 대금을 받으세요. bounty는 미리 자금이 확보되며 병합 시 지급됩니다.

플랫폼 수수료 없음

개발자는 bounty의 100%를 가져갑니다. PrTask는 클라이언트에게만 청구하며 기여자에게는 청구하지 않습니다.

공개 pull request

모든 작업은 GitHub의 실제 pull request로 제출됩니다. 당신의 기여는 공개되며 검증 가능합니다.

작동 방식

1

Sign In

PrTask 계정을 만들려면 선호하는 싱글 사인온 제공업체로 인증하세요.

2

작업 둘러보기

언어, 프레임워크 또는 bounty 금액별로 필터링된 사용 가능한 작업을 찾아보세요.

3

pull request 제출

작업을 선택하고 코드를 작성한 뒤 대상 저장소에 pull request를 여세요.

4

대금 받기

당신의 pull request가 검토되고 병합되면 bounty가 자동으로 계정에 지급됩니다.

보안 및 신뢰

PrTask는 OAuth 기반 SSO만 사용합니다. 비밀번호를 저장하지 않습니다. 모든 결제는 작업이 검증될 때까지 에스크로에 보관됩니다.

도움이 필요하신가요?

가이드, 자주 묻는 질문, 지원 자료는 문서를 확인하세요.

도움이 필요하신가요?

PrTask에 로그인 - 안전한 인증 옵션

PrTask는 신뢰할 수 있는 ID 제공자를 통한 싱글 사인온(Single Sign-On, SSO) 인증을 사용하여 계정에 대한 안전한 접근을 보장합니다.

PrTask의 대부분 기능에 접근하려면 금융 거래와 코드 기여에 검증된 신원이 필요하므로 인증이 필수입니다. 처음 로그인할 때 PrTask가 계정을 자동으로 생성하고 선택한 신원 제공자와 연결합니다. 개발자는 GitHub 계정을 연결해 pull request 제출 과정을 간소화할 수 있으며, 고객은 시장에서 신뢰를 높이는 검증된 신원의 혜택을 받습니다. 모든 인증 데이터는 암호화된 연결을 통해 전송되며 PrTask는 신원 제공자의 비밀번호를 절대 저장하지 않습니다.

개발자에게는 로그인으로 작업 탐색, pull request 제출, 보상 획득, leaderboard 순위 추적 기능이 열립니다. 고객에게는 인증을 통해 작업 생성, 보상 자금 조달, pull request 검토, 결제 관리가 가능해집니다. PrTask는 여러 연결 계정을 지원하므로 코드 제출용 GitHub와 일반 인증용 Google 계정을 연결할 수 있습니다. 로그인 후 Settings 페이지에서 연결된 계정을 관리하고 결제 수단을 설정하며 보상 출금을 위한 KYC 인증을 완료하세요.
