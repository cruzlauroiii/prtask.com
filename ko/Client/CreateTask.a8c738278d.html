새 작업 만들기

보상이 있는 작업을 게시하여 개발자를 유치하세요.

플랫폼 수수료 없음 — 개발자는 보상의 100%를 받습니다.

작업 생성 — 개발 업무에 보상 게시

‘작업 생성’ 페이지에서 고객은 PrTask 마켓플레이스에 새로운 개발 과제를 올립니다. 각 작업에는 명확한 제목, 상세 설명, 연결된 GitHub 리포지토리 URL, 그리고 완료 시 개발자가 받을 보상액이 필요합니다. 폼은 모든 설정 항목을 안내해 개발자가 무엇을 해야 하고, 작업이 얼마나 복잡하며, 얼마를 벌 수 있는지 알 수 있게 합니다. 정의가 잘 된 작업은 더 자격 있는 개발자를 끌어들이며, 빠르고 품질 높은 제출로 이어집니다.

복잡도 수준(매우 단순, 단순, 보통, 복잡, 전문가)은 개발자가 작업 수용 전 필요한 노력과 기술을 가늠하도록 돕습니다. 복잡도는 정직하게 설정하세요. 낮게 설정하면 불완전한 결과를, 높게 설정하면 시도조차 하지 않게 됩니다. 보상은 작업의 복잡도와 가치에 맞아야 합니다. PrTask는 의미 있는 보상을 위한 최소 금액을 요구하며, 개발자는 숨겨진 공제 없이 전체 금액을 확인합니다. 태그는 기술과 유형별로 작업을 분류하여 더 쉽게 찾을 수 있게 합니다.

Epic, Feature, Story, Task, Bug 등 작업 항목 유형을 프로젝트 관리 방식에 맞게 설정하고, 공개 또는 비공개 가시성을 선택할 수 있습니다. 공개 작업은 모든 개발자가 볼 수 있고, 비공개는 초대한 사람만 접근할 수 있습니다. 작업 제출 후 즉시 Tasks 페이지에 올라가 개발자가 찾고 작업을 시작할 수 있습니다. 우승한 Pull Request를 승인하고 병합하면 보상이 처리되며, 요구사항을 충족하고 코드 리뷰를 통과한 작업에만 비용을 지불합니다.
