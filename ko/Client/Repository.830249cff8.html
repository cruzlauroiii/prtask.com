아직 추가된 리포지토리가 없습니다. 작업 게시를 시작하려면 리포지토리를 추가하세요.

저장소 관리 - GitHub 저장소를 연결하고 구성합니다

리포지토리 페이지에서는 클라이언트가 자신의 GitHub 리포지토리를 PrTask에 연결하여 작업을 원활하게 게시하고 코드를 안전하게 관리할 수 있습니다. 공개 또는 비공개 리포지토리를 추가하고 각 작업의 소스 코드를 누가 볼 수 있는지 제어할 수 있습니다.

PrTask에서 체계적인 개발 워크플로를 유지하려면 연결된 리포지토리 관리를 하는 것이 중요합니다. 작업을 생성할 때 연결된 리포지토리 중 하나에 연결하면 개발자가 코드 기여를 어디에 제출해야 하는지 정확히 알 수 있습니다. 공개 리포지토리는 마켓플레이스 참가자 모두에게 표시되어 오픈 소스 프로젝트와 커뮤니티 주도 개발에 이상적입니다. 비공개 리포지토리는 초대된 개발자에게만 접근을 제한하며, 코드의 열람과 기여 대상을 통제하려는 독점 코드베이스에 적합합니다.

PrTask는 표준 API 연결을 통해 GitHub와 통합되며, 링크를 설정하는 데는 리포지토리 URL만 필요합니다. 리포지토리에 대한 전체 제어는 유지됩니다 - PrTask는 리포지토리 설정, 브랜치 보호 또는 접근 권한을 변경하지 않습니다. 모든 풀 리퀘스트 리뷰와 머지는 기존 GitHub 워크플로를 통해 수행되며, PrTask는 바운티 결제와 작업 상태 추적을 자동으로 처리합니다. 리포지토리를 더 추가하면, 리포지토리 페이지가 PrTask 마켓플레이스에 연결된 모든 코드베이스의 중앙 디렉터리 역할을 합니다.
